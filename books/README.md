# 书籍与经典研读库 (Books & Classics)

本目录用于沉淀经典著作、思维模型、中西方兵家法家与管理学/认知科学书籍的研读笔记、思维导图映射与长期思考。

## 定位与设计原则

1. **同级协同与分流**：
   - 商业实操与产业分析放入 `thinking/business/`；
   - 政治力学与制度演化放入 `thinking/politics/`；
   - 经典著作原文脉络、书目提炼与跨学科底层思考放入 `books/`（作为底层认知与思维武器库）。
2. **拒绝流水账，提炼模型**：不搬运图书全文，只沉淀**核心公理、反直觉推论、思维模型与实战决策抓手**。
3. **外部链接与导图映射**：记录云盘/腾讯文档导图与文档的索引地址，便于快速溯源。

## 目录结构

- `README.md`：本目录说明与架构索引。
- `sources.md`：外部云盘、导图、在线表格与原文档案全景索引。
- `reading-list.md`：阅读与精读进度清单。
- `notes/`：按主题沉淀的书籍深度笔记与思考手记：
  - `strategy-and-military/`：战略、兵法与法家（孙子兵法、韩非子、管子、鬼谷子、罗织经）。
  - `philosophy-and-methodology/`：哲学、认知与思维模型（道德经、资本论、哲学方法论、思维模型库、决策思维）。
  - `management-and-business/`：管理、效能与商业智慧（德鲁克、给经理人的第一课、纳瓦尔、DAN KOE、时间管理高手修炼）。
  - `politics-and-power/`：权力动力学与政治经典（独裁者手册等，与 `thinking/politics/` 双向联动）。
  - `psychology-and-education/`：心理学与教育（心理学、家长教育误区）。
