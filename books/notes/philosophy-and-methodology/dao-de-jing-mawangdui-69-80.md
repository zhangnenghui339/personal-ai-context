```
│ 结构层  74 刀令分离  ·  75 抽取有上限、归因在上                │
│         77 资源从有余流向不足（负反馈必须人工建造）            │
│         79 执契而不责（冲突前移，不生大怨）                    │
├───────────────────────────────────────────────────────────────┤

├───────────────────────────────────────────────────────────────┤
```

## 1. 帛书定本与关键异文汇总表

> 只列**承载论证**的异文。凡标「存疑」者，本笔记的推论均不依赖它（详见 §7）。

| 章 | 帛书关键读法 | 通行本 | 篡改造成的认知降维 |
|---|---|---|---|
| 69 | `執無兵，乃無敵矣`（四重递进，以"无敵"作结） | `扔無敵，執無兵`（并列） | 帛书是"因无形故不构成敌我"；通行本把结果混成并列项，逻辑落点丢失 |
| 69 | `禍莫大於無敵`（乙本读法有争） | `禍莫大於輕敵，輕敵則幾喪吾寶` | 两读并存：「无敵」说因（自以为无敵），「轻敌」说果。通行本保留了与 67 章「三宝」的呼应 |
| 70 | **`言有君，事有宗`** | `言有宗，事有君`（次序颠倒） | 帛书是严格层级：言与事都是被生成的**输出**；通行本降为"说话有宗旨、做事有主见"的训诫 |
| 70 | **`知者希，則我貴矣`** | `知我者希，則我者貴` | 帛书是**结构性稀缺定律**；通行本加"我"塌缩为个人怀才不遇 |
| 70 | 无 `是以聖人被褐懷玉` | 有 | 通行本增补后，从认知经济学变成贤人抱璞的文学造型，并助长以稀缺自我加冕 |

| 77 | `猶張弓者也`（判断句） | `其猶張弓與？`（设问） | 帛书下定理，通行本打招呼 |
| 77 | `損有餘而益不足`（`益`，存疑） | `補不足` | `補`＝填平回基线；`益`＝主动增益，与 76 章"生长在末端"咬合 |

## 2. 各章机制要点

### 69｜不敢为主而为客

- **核心**：不使对抗结构成立，而非在对抗中取胜。`行無行，攘無臂，執無兵` → `乃無敵`。
- **曲线**：为客／退尺（示弱）→ 无形无迹（示无）→ 对抗消解（得势）→ **急转警告得势本身** → `哀者勝`（回到 `慈`）。
- **可迁移**：不做发起者（让正当性站在你这边）；不给对方可着力的形状；赢势之时最危险。

### 70｜言有君，事有宗

- **核心**：道是低描述长度的生成规则（`易知易行`），但接收方缺解码器（`莫能知`）、跨不过相变能垒（`莫能行`）。
- **飞轮**：生成器层 → 涌现 → 现象层 → 世人在此采样 → 过拟合（四自）→ 莫能知行 → **负反馈锁死** → `知者希` → 知者的认知租金永不衰减。
- **判据**：`可逆+她担后果+能力够` 式的层级思维在此的版本是——**动作可以抄，条件不能抄**；"为执行它我本季必须放弃什么"填不出，说明掌握的是措辞。

### 71｜不知不知，病矣

- **知识四象限**：②已知的未知（`知不知`，可对冲）vs ④未知的未知（`不知不知`，遭遇即破产）。二者知识量同为零，差别只在**是否登记在账面上**。
- **最深一层**：`病` 的数学身份是**教条先验**（先验概率设 0）→ `posterior = likelihood × 0 = 0` → **学习率归零**。知识少可补，更新机制被关闭无法补。
- **自察无效定律**：二阶无知在定义上不可自我检测；任何"提醒自己谦虚"的方案，都在用故障模块检测自身故障。**处方必须外部化。**

### 74｜不代司杀者

- **威慑分解**：`D = P(必) × S(重) × C(可信)`；老子全部重量押在 `P`（`為畸者恒死` 的重点是"一定"）。
- **饱和**：最重手段一旦无效，问题不在手段，在于已用到饱和；继续加码只消耗权威存量。
- **结构**：规则独立于人 → 怨恨指向规则；主权者兼任执行位 → 怨恨有了具体地址，规则丧失独立权威 → `傷其手`。
- **一句**：`令与刀，不可同在一手`。令要恒定，刀要临场；令可议，刀不可商。分开后才解锁"一边执行它，一边抱住被它伤到的人"。

### 75｜归因反转

- 三句主语全是民，三个原因全指向上：`取之多`→飢；`求生之厚`→輕死；`有以為`→難治。
- **级联**：抽取过度 → 存量被抽干 → 可失去之物归零 → 威慑分母为零 → 74 章的"民不畏死"。**74 是症状学，75 是病因学。**
- **自毁环**：怕失位 → 加控制加抽取 → 更难治 → 更怕失位。**为降低自身风险而采取的措施，成为风险的最大来源。**
- **古德哈特飞轮**：`有以為` → 下方针对指标优化 → 真实信号被覆盖 → 上方信息变差 → 加更多干预。`難治` 是干预的副产品。

### 76｜柔弱者生之徒

- **五个取象领域**：人身（柔弱／堅強）、草木（柔脆／枯槁）、军事（兵強則不勝）、木材（木強則折）、方位（強大居下／柔弱微細居上）。
- **论证三层**：举证（人＋草木，覆盖动植两界）→ 推论（`故曰`）→ 验证（兵＋木，覆盖人事与物质）→ 结构结论（居上／居下）。
- **每个领域用各自的词**（草木是 `柔脆／枯槁` 而非 `柔弱／堅強`）⇒ 不是比喻外推，是**四次独立观察**。
- **`柔脆` 二字的精确化（重要）**：嫩芽一掐就断但活着，枯枝掐不断但死了。所以本章讲的**不是"柔者不易受伤"，而是"柔者在生的方向上"**。"韧性抗冲击"是现代工程引申，不是原文命题——两者都有用，不应混为一谈。
- **工程引申（自己加的，非原文）**：刚体只能传递能量、柔体可耗散；柔＝剩余自由度多；`選項計數法`：只剩一个可行选项，即已在堅強一侧。

### 77｜天之道是负反馈

- **张弓＝伺服回路**：高者抑之、下者举之——负反馈的标准描述。注意两点：① `天之道` 不是躺平，压与抬都是主动动作；② 调弓的目的是射出去，负反馈维持的结构才能积累势能。
- **`損不足而奉有餘` 的数学身份＝优先连接**（新节点优先接入高度节点 → 幂律）。**它不需要任何人心存恶意，是缺乏负反馈时的默认演化方向。**
- **最实用一句**：`正反馈自动发生，负反馈必须人工建造。`
- **损有余对持有者本人有利的三条功利理由**：边际产出（多余部分在你手里产出最低）、持有成本（剩余＝变硬＝脆性来源）、秩序成本（主动回流是最便宜的秩序维护费）。
- **`為而弗有`**：不成为分布里那个"高者"，故不触发校正机制。

### 78｜受邦之诟

- **水胜坚强的五机制**：① 时间分摊（前提是你一直在）② 无形态→无受力点 ③ 全向施压→必中最弱方向 ④ 渗透→不在表面作战 ⑤ **无疲劳累积**。
- 第⑤条最深：**刚体每一次胜利都更接近断裂，水的每一次作用都不减损自身。**
- **`無以易之`（取"无法使它改变"读法）**：水攻坚而胜，因为它从不为攻坚而变硬。对抗强硬对手时变得同样强硬＝放弃唯一优势、进入对手主场。
- **与 70 章的分工**：70 是知行双双失守；78 是**知没问题，只有行失守**，且立刻给出原因——行的代价是承受责骂。**门槛不是认知门，是羞耻门。**
- **`正言若反` 作为粗筛判据**：正确的策略处理二阶因果，故在一阶直觉上必然显得颠倒。完全顺耳的策略大概没有超额收益。**但反直觉是筛子不是证明**，须配可证伪性（71 章）。

### 79｜执契而不责

- **`和大怨，必有餘怨`＝信任的塑性变形**：小摩擦在弹性区可完全回弹，大怨越过弹性极限后留永久残余。**调解的上限是减轻，不是清零。**
- 推论及其逆否：治理重心须前移到"不产生大怨"；**一个特别擅长灭火的组织，是因为它在持续放火。**
- **`執契而不責`＝保有权利，不行使权利**，是 74 章的私法版（執契＝令在我，不責＝刀不在我）。行使追索权的那一刻就是怨恨的生成时刻。
- **`有德司契，無德司徹`**：管规则 vs 管催收。岗位自检：本周时间花在哪一侧。
- **`天道無親，恒與善人` 的唯一不矛盾读法**：`善`＝善于、擅长。天道不奖励好人，它只是**无例外地结算**；正因无偏私，结果完全由是否顺应机制决定。与 77 章严密咬合。

### 80｜器闲兵不陈（验收单）

- **枢机**：三句主语全是 `有`——`使有十百人之器而毋用`、`有車舟無所乘之`、`有甲兵無所陳之`。**`無所用` 是结果，不是禁令。** 老子没有要求销毁任何东西。
- **应急能力使用率**：ICU 空床、消防闲置、法院案少、公关无事——**使用率高不说明能力强，说明问题多。** 是 79 章"擅长灭火＝持续放火"的正面镜像。
- **冗余的悖论**：冗余在账面上永远像浪费；**一旦你必须使用它，它就不再是冗余。**
- **`小邦寡民`＝低耦合**，不是崇尚落后。紧耦合大系统必须配备大量"十百人之器"（重型协调机制、层层监管、危机管理部门）——**这些器械的存在本身就是耦合过度的证据。**
- **`民至老死不相往來` 是架构描述**：前文 `鄰邦相望，雞狗之聲相聞`（物理邻接）＋不相往来（功能独立）＝低耦合的标准定义。**不是禁止交流，是不需要相互依赖就能各自过好。**
- **`甘其食，美其服,樂其俗,安其居`** 四个都是主观状态，是 75 章"不取之多"的兑现形态，也是 74 章威慑分母的来源。

## 3. 跨章统一线（四条）

**线一｜留即柔，且要流向末端**

```
71 留先验方差（不把未知赋值为零）   ← 认知的柔
74 留最重手段（永不用尽）           ← 权力的柔
75 留民之存量（不取尽）             ← 系统的柔
76 给出总原理：凡「留」者皆柔，凡「尽」者皆硬
77 补上方向：留还不够，要让它流向不足处
80 验收：所有重型能力处于待用而不用
```

**线二｜把「我」放回因果链**（这是全部认知处方的共同结构）

```
70 把「言」当作「君」         → 把输出当输入
```

**线三｜局部最优的加总可以是全局自杀**
