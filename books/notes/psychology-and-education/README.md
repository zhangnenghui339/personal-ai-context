# 心理学与家庭教育 (Psychology & Education)

本目录沉淀认知心理学、行为决策偏误与家庭教育反常识模型的思考手记。

## 包含书目与导图映射

- `psychology.md`：《心理学基础与认知机制》（进化心理学、偏误修正、行为强化）| [专栏源](https://docs.qq.com/desktop/mydoc/folder/HbigXMxLVXAh)
- `parenting-fallacies.md`：《家长教育误区与反常识模型》（正反馈构建、去说教化、心理资本）| [导图源](https://docs.qq.com/mind/DSHBMS0tjaE5JYWJM)
- `father-case.md`：《父亲案例分析》（熟人共同体观众席三变量与合法性耦合判定器；象征性支付＝「一句话的门槛」；位置补偿律与逆向感谢律；验收回路无接线；展品与展柜逻辑；封闭回路与停止投标策略；观众席的代际传递；建议源的偏倚——持仓—发言背离、部署时机即证据、动机性推理不可质询、不可逆窗口上的双重计费）
- `mother-case.md`：《母亲案例分析》（**father-case 的对子篇**：照护按给予者安全感定价；输入回路无接线；照护的自我指涉＝质量指标存放在给予者手里；零成本判据——成本不是约束、品类才是约束；耗尽式劝说与代理接管；固化的创伤参数不可用资源修正；欲望的道德化＝「我想要」需要先出具理由；双重销账；定性为「受垢者＋不响应的照护者」；育儿正解＝加一个征询动作；**受益人约束**＝约束既非价格也非出钱人，而是受益人（一次变量隔离的对照）；**四份凭证**＝社会常规／可撤销／价格合规／有用，审批已内化；**免为难**＝关闭需求是为了免除供养者的道德处境，故「我负担得起」会加剧而非缓解；需求羞耻三层（不在名单上 ≠ 排在后面）；可反驳型 vs 不可反驳型理由——给`场合`不给`理由`；**代为决定 vs 征询**的分界判据＝有没有对方自己产生的信号；等待即成本；**评价＝无位置者的参与申请**，只回应内容它会换个说法再来）
- `daughter-case.md`：《女儿案例分析》（**father-case / mother-case 的下一代篇**：禁令缺失＝高回应＋低要求，崩溃点在禁令之后的承受期；对象误认＝制止时的痛来自内在小孩，受益人是施动者；反面即同轴——「我要安心」与「我会痛」是同一条轴的两端；勉强 vs 约束的`受益人 × 时间尺度`判据与「最危险一格」；补偿式育儿脱靶＝按匮乏清单而非需求清单给予；安全基地的第二属性＝稳定；**杠杆假说已在冲突现场检验、三项全空、正式撤回**，回执改挂三条行为证据（主动报告困难／哭完次日恢复／冲突不升级到关系层面）；让步归因判据——给新信息才调整、闹不让步；仪式性文本不可用作诊断；三步现场脚本与低代价样本积累；断链点在叙述不在经历——AAI 与 earned secure）
- `self-case.md`：《自我结构分析》（**父母两篇与 daughter-case 之间的中间环节**：三条无回执回路＝有输出无回执，故无力感是正确推论而非情绪故障；双通道关闭——「不被看见」关接收端、「不被允许」关发送端，合并即「空心」；强迫性自立＝不敢依赖，源于一次当时正确的成本比较；燃料类型＝代偿型执行力以焦虑为燃料，强与瘫痪是同一机制两端；可展示的伤口；解禁 ≠ 学习——「我想要」通道重建六条与「三理由判据」；样本量而非系统——友谊中已验证可舒适接收回应）
- `daughter-screen-log-method.md`：《屏幕时间的测量方法》（**方法篇**，配套 daughter-case：口径先于数字——`申请 ≠ 批准 ≠ 实际使用`，未标口径即软证据；证据分级与反直觉结论——最硬的是孩子自己的申请记录，因为发起、定量、索要批准三个环节全在她那侧；**有出口的证据才可用**，没有出口的证据等于没有；记录自己提出的申请 ≠ 检查私域；「作业做不完」的怀疑顺序＝负荷 → 困难 → 挤占，顺序错则情绪成本白付；`负荷 × 屏幕`交叉表与 `T+S>W` 时间预算物理不可行判据；记录表三条约束——1 分钟上限、不设无法合法取数的列、**必须含父母自己的行否则是监控报告**；硬证据使用规则——交给对方看而不是念给对方听、不在情绪事件后削减、不悄悄少批）
