# Personal AI Context

面向 AI 协作的私人知识库：项目背景、决策、任务、提示词、读书笔记和长期思考。

## 使用原则

- 只记录未来会影响理解、决策或行动的信息。
- AI 先读 `_meta/router.md` 定域，再加载对应角色和最小记忆；`CONTEXT_INDEX.md` 只作篇目索引。
- 项目事实以对应项目的 `status.md` 和 `decisions.md` 为准。
- 不提交密码、Token、Cookie、私钥、证件、医疗原件及其他高敏感数据。
- 完整电子书不进入仓库，只保存书目信息、摘录索引和个人笔记。

## 快速入口

- 行为总纲：`_meta/router.md`
- 跨工具启动词：`_meta/boot-prompt.md`
- Cursor 入口：`AGENTS.md`（指向 router）
- 篇目索引：`CONTEXT_INDEX.md`
- 角色：`prompts/roles/`
- 快速收集：`tasks/inbox.md`
- 项目模板：`projects/_template/`
- 决策模板：`templates/decision-record.md`
