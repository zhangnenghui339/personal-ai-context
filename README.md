# Personal AI Context

这是一个面向 AI 协作的私人知识库，用于保存项目背景、关键决策、亲子与教育记录、任务、提示词、读书笔记和长期思考。

## 使用原则

- 只记录未来会影响理解、决策或行动的信息。
- AI 先读取 `CONTEXT_INDEX.md`，再按任务加载最小必要上下文。
- 项目事实以对应项目的 `status.md` 和 `decisions.md` 为准。
- 不提交密码、Token、Cookie、私钥、证件、医疗原件及其他高敏感数据。
- 完整电子书不进入仓库，只保存书目信息、摘录索引和个人笔记。

## 快速入口

- AI 路由：`CONTEXT_INDEX.md`
- AI 协作规则：`AGENTS.md`
- 快速收集：`tasks/inbox.md`
- 项目模板：`projects/_template/`
- 决策模板：`templates/decision-record.md`
