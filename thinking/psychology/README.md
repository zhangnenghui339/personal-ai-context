# 心理思考

本目录沉淀以自身体验为起点、用心理学理论对照道家思想的长期笔记。关注点不是症状标签，而是机制：某种反复出现的心理模式背后，心理学和道家各自看到了什么，两者在哪里重合。

## 使用边界

- 区分：有实证支撑的心理学理论、个人体验、个人判断与推论。
- 引用理论时尽量标出提出者与年代，便于回头查证；未查证的表述标为推断。
- 道家部分以《道德经》《庄子》通行本为准，解读为个人整理，非逐字直译。
- 这些笔记不是临床诊断，也不替代专业帮助。
- 新结论与旧记录冲突时不静默覆盖，注明日期、证据与被替代结论。

## 文件结构

- `anxiety-iu-and-no-guarantee.md`：焦虑的四层机制与"无保证"关系重建（不确定性不耐受、担忧回避、威胁置换、绝对确定；出路不是更好的保证，而是改变与"无保证"的关系）。
- `neuroticism-and-mate-selection.md`：神经质与择偶（神经质三层定义、吞噬关系的四步机制、双高组合风险、人格障碍在关系中的模式、"只看经济条件"漏掉的风险、择偶评估框架与人格红线；引述数据标为待查证）。
