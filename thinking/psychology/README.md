# 心理与心智机制

本目录沉淀可复用的心理机制、焦虑回路与自我/注意力结构，并与仓库内已有的老子、庄子、默多克去我模型对接。

## 使用边界

- 区分：可验证的临床/研究机制、个人判断、待身体验证的假设。
- 机制记录用于理解与行动切分，不作疾病诊断，也不替代法律或医疗意见。
- 案例只保留足以说明机制的结构，不写入证件号、账户、医疗原件或其他高敏感数据。
- 新结论与旧记录冲突时不静默覆盖，注明日期、证据与被替代结论。
