# 政治研究

本目录用于沉淀政治制度、政治经济学、国际关系、公共政策与具体政治事件的长期研究。

## 使用边界

- 区分：可验证事实、来源观点、分析推断、价值判断。
- 涉及时效性事实时，记录事件日期与信息来源。
- 优先使用法律原文、政府文件、统计资料、学术论文等一手来源。
- 对争议问题至少呈现主要竞争性解释，不把立场写成事实。
- 不保存未经验证的传闻、个人敏感信息或煽动性材料。
