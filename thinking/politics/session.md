## 1. 政治第一性原理与三元大统一（元模型）

> **政治第一性原理**：
> 人类为了解决「暴力分散时的负和耗散（互掠）」，通过将暴力合法垄断为一个公共做功场（制度基础设施与安全介质），从而允许全社会进行超线性正和分工做功，并在此基础上建立一套关于「剩余索取权（水龙头地租）」的排他性分配与合法化系统。

```
┌────────────────────────────────────────────────────────────────────────────────────────┐
│                      政治底层三元大统一架构 (The Political Triad)                        │
├────────────────────────────────────────────────────────────────────────────────────────┤
│ 1. 利益 (Interests / Mass-Energy)   ➔ 【系统质能】：势能源泉、剩余索取权、生存与地租收益 │
│ 2. 力学 (Mechanics / Field-Physics) ➔ 【物理场域】：暴力垄断、空间阻尼、超导介质、承载极限│
│ 3. 博弈 (Game Theory / Algorithm)   ➔ 【交互算法】：信息结构、承诺困境、联盟算术、纳什均衡│
│ +  技术 (Technology / State Var)    ➔ 【外生变量】：不定期重写暴力成本与通信阻尼的造物主  │
└────────────────────────────────────────────────────────────────────────────────────────┘
```

## 4. 政治分析的 5 问降噪自检滤镜（新会话快速分析工具）

审视任何政治事件、制度变迁、政变或公共政策时，直接调用这 5 个问题：

1. **利益流向**：这项政策让谁获得了真金白银的特许地租，让谁承担了无法转移的隐形成本？
2. **制度几何**：领导人这是在向他的哪一部分制胜联盟（$W$）兑现分红？还是在向新盟友拉拢？
3. **承诺机制**：各方的合作是靠道德口号，还是靠不可逆的物理抵押与制度制衡？
4. **协调阻尼**：受损群体的横向组织与串联成本有多高？谁垄断了通信网络与议程设置权？
5. **做功场健康度**：这项举措是在给 L1 经济做功场降低摩擦，还是在通过 L2 暴力抽水吸干整个社会的做功底座？
