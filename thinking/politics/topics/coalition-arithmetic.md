## 核心判断

【个人判断】这六句是**夺权与维持执政联盟的操作手册**，不是政治的完整本体论。完整本体论见 `thinking/politics/topics/politics-first-principles.md`：止掠做成可征税的生产场，再规定剩余归谁。六句只覆盖后半句。

压缩成一句没有错：政治首先是把「自己的人」变多、把「对方的人」变少。这里的「搞」确实包含团结、拉拢、放弃、孤立、打击、利用。它解释的是**关系操作**，不解释三件同样决定存续的事：

1. **切割本身怎么被定义**：谁算自己人，是斗争的产物，不是先验名单。
2. **赢了以后怎么把联盟变成可预期制度**：否则「搞」永远停在清洗名单上。
3. **剩余从哪来**：没有可分配的剩余，统一战线只能靠许诺和下一次打击续命。

【个人判断】当作**首要问题**成立；当作**唯一本质**会误判。它与本库商业侧的「分发优先」同构：必要，且经常被学院派漏掉；但分发不是企业的全部，联盟算术也不是政治的全部。

## 六种操作不是同义词，是一组久期不同的关系头寸

| 操作 | 对象 | 支付 | 久期 | 失败态 |
|---|---|---|---|---|
| 团结 | 核心自己人 | 身份、保护、长期剩余索取权 | 长 | 内部分赃不均 → 分裂 |
| 拉拢 | 中间派 / 可交易盟友 | 利益交换、妥协、给面子 | 中 | 价码涨到买不起，或被对方加价挖走 |
| 放弃 | 难争取或净值低的群体 | 不投入 | 主动收缩 | 当断不断；或误弃关键swing |
| 孤立 | 对手的外围与合法性 | 切割、分化、道德/力量上使其失援 | 中 | 叙事破产 → 孤立者变受害者 |
| 打击 | 核心威胁 / 顽固对手 | 强制、剥夺行动空间 | 短而硬 | 制造烈士、安全困境、扩大敌人集合 |
| 利用 | 临时可用力量 | 阶段性目标，不承诺终局席位 | 短 | 被看穿 → 以后没人来；或反噬 |

【推断】六句里真正的杠杆不在「打击」，在**分类**：每次行动都在改写「朋友/中间/敌人」的边界。分类错了，后面五句都是在给错误集合做功。

【事实】毛泽东把「谁是我们的敌人，谁是我们的朋友」写成革命的首要问题（1925《中国社会各阶级的分析》）。列宁传统的操作句是：利用矛盾、争取多数、反对少数、各个击破。用户这六句是同一套统一战线算术的动词化。

【事实】「没有永恒的敌人，只有永恒的利益」不是中国原创。帕麦斯顿（Palmerston）的表述是：国家没有永久的盟友或敌人，只有永久的利益。它约束的是**拉拢/利用的可翻转性**，不能用来取消「团结」所需的最低信任。

## 这套算法在自身逻辑上会自我拆台的四个点

### 1. 「利用」折损「拉拢」的贴现因子

【推断】若中间派预期「用后即弃」，当前要价会上升，或根本不来。权宜之计用一次是战术；成为共同知识就是战略负债。兔死狗烹不是道德故事，是**声誉作为联盟资产被一次性套现**。

与「没有永恒的敌人」同时成立时，必须补一句：【个人判断】**可以没有永恒的敌人，但不能没有可核验的履约。** 否则只剩下打击，拉拢市场关闭。

### 2. 「打击」若没有「孤立」，敌人集合不减反增

【推断】打击的会计恒等式不是「少了一个对手」，而是「对手的支持者是否改登记到我方、中立，还是登记到对方」。没有道义/利益上的孤立，强制只改变强度，不改变人数。

「把敌人陷于人民战争的汪洋大海」【个人判断】是结果描述，不是独立武器。它预设「人民」已经被团结+拉拢写成多数主体。若人民只是口号，汪洋大海是空的。

### 3. 缩小联盟能赢斗争，也会吃光剩余

【事实】Selectorate / 获胜联盟理论（Bueno de Mesquita 等）：维持执政所需的核心人数越小，领导者越倾向提供私人物品而非公共物品；核心过大则必须提供更广的好处。

【推断】六句法若被执行为「不断清洗到只剩铁杆」，短期更稳、长期剩余枯竭、信息失真（下属只报敌情）。这是独裁者困境，不是价值判断。

### 4. 最难的一步被六句法跳过了：改切割标准

【个人判断】「黑猫白猫」与按成分团结/打击，是**互相竞争的分类规则**。前者把识别函数从出身改成绩效，等于重画朋友名单，而不是在旧名单上多团结几个。

邓的猫论【事实】是实用主义的绩效合法性，不是统一战线手册的第六款。把它塞进「利用」，会丢掉它真正的升维：改变谁算自己人。

## 竞争性解释（都要保留，不把其中一种写成事实）

**A. 施米特（Schmitt）**：政治的划分就是朋友/敌人。用户模型是施米特的操作手册。强处：能解释战争、革命、清党。弱处：解释不了为什么有的政体让失败者明天还能赢。

**B. 自由制度主义 / Przeworski**：民主是失败者接受失败，因为规则让他们以后还有赢的概率。此时「把对方的人搞得少少的」若变成消灭再进入权，游戏本身结束。六句法在竞选联盟层面有效，在毁灭对手作为玩家时无效。

**C. 最低获胜联盟（Riker）**：理性政党只拉刚好赢的多数，拉过多要分赃。这修正「朋友搞得多多的」——【个人判断】**多多不是目标，刚好能赢且能供养才是目标。** 人多是手段，剩余索取权的集中才是约束。

**D. Olson 固定匪帮**：若统治者预期长期占有一块地盘，他有激励把饼做大再征税。六句法只处理「谁站哪边」，不处理「这盘饼要不要做大」。本库商业模型里的筑坝/收租，对应的是这一层，不是前一层。

**E. 建构人民（Laclau 等）**：人民不是点出来的，是叙事拼出来的。孤立/团结的效率取决于你能不能让中间派用你的语言描述自己。纯利益交换的拉拢，贵且不稳；带身份的团结，便宜但改切割时很痛。

## 与制度类型的匹配【推断】

| 场景 | 六句法效力 | 主要约束 |
|---|---|---|
| 革命、派系战争、建政初期 | 高 | 分类错误、过早清洗盟友 |
| 选举竞争（联盟与动员） | 中高 | 不能从物理上消灭对方选民 |
| 高能力常规国家日常治理 | 中低 | 官僚、法律、财政把「打击」变成高成本 |
| 国际体系 | 中 | 无最高裁判，利用/拉拢的声誉贴现更陡 |

【个人判断】把战时手册当治理宪法，是这套观点最常见的过拟合。

## 和本库其他模型的接口

- 商业「分发优先」：先解决谁能看见/站哪边，再谈产品。政治六句是同一层。
- 商业「套利 → 筑坝 → 收租」：六句停在套利/联盟层。筑坝 = 把临时联盟写成制度（税、军、组织、叙事）；收租 = 对管道上的行动征税。只搞人、不筑坝，是流寇。
- 机会发现「分发权 vs 分发入口」：团结是试图持有分发权；拉拢/利用往往只是租来的入口。
- 城镇化与势能：六句的空间译本见 `thinking/politics/topics/urbanization-coalition-momentum.md`。城市把「搞人」落成「接不进高阶生产函数」；土地财政是这套阀门的会计分录。
- 全部本质：`thinking/politics/topics/politics-first-principles.md`。L0 止掠 → L1 做功规则 → L2 剩余索取（六句）→ L3 对照基准。

## 可用的压缩版（给下一会话）

1. 政治的**首要运算**是联盟算术：改写朋友/中间/敌人的人数与动员强度。
2. 六种动词按**承诺久期**排序，不是同义反复；混用会自毁声誉。
3. 目标不是朋友最大化，是**可供养的获胜联盟** + **不把中间派市场关掉**。
4. 赢之后要换坐标系：从名单斗争转到剩余生产与制度承诺，否则清洗会吃掉江山。
5. 最高阶操作不是多团结一个，是**改识别函数**（谁有资格当自己人）。

## 待验证

- 用户口述中的「三届齐立」「一将胜永追成寇」「学霸王」：按语境分别更接近兼收并蓄/权宜、一将功成万骨枯、毋学霸王。不把错记的成语当文献。
- 这套操作在数字舆论场（平台算法当「人民」）是否改变孤立/打击的成本结构——待专题。
- 与具体政体（中/美/选战/党内）的系统回测，未做。韩国 12.12（1979）已做单案例回测：`seoul-spring-1212-coalition-game.md`。结论：核心能力是「按久期把剩余索取权卖给刚好能赢的节点」，不是发钱，也不是人多。
