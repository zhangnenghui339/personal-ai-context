# 首尔之春 / 12.12：利益分配、拉拢与最低获胜节点

- Date: 2026-08-19
- Status: 用本库六句法与 $N,S,W$ 回测 1979-12-12 韩国军事叛乱。回答「政治家最核心能力是否就是利益分配与拉拢」。

## 核心判断

【个人判断】**「利益分配 + 拉拢」是政治家的首要运算，不是政治的全部本质。** 12.12 把它钉死在一个可检验的晚上：

1. **分配的不是现金，是剩余索取权**：朴正熙死后，谁还能进入军职晋升管道、谁能保住性命与指挥权、谁能事后把叛乱写成「合法调查」。
2. **拉拢的对象不是「人多」，是能改写结果的节点**：保安司通信网、首都警备关键营、特战旅长、国防部长的签字、青瓦台的追认。
3. **对方输在「有法统、无联盟」**：郑升和/张泰玩握有纸面指挥链，却无法把部下写成自己的 $W$。全斗焕握有私党（하나회 / Hanahoe），并把对方的旅长改登记到己方。

【个人判断】把 12.12 看成忠奸剧，会得出错误课：好人该赢。把它看成联盟会计，课才成立：**先分类，再按久期付钱，同时切断对方的横向协调。**

## 2. 那天晚上在分什么「利益」（三层金字塔）

10.26 把韩国军政的 L0 暴力垄断重新拍卖。分配物不是 GDP，是广义利益：

| 层 | 12.12 的具体筹码 | 谁在竞价 |
|---|---|---|
| 物理层 | 不被逮捕、不被调往闲职、不在枪战中被击毙 | 郑升和、张泰玩、郑炳宙 vs 하나회 将领 |
| 经济层 | 今后十年的军职、采购、维新余党的特许管道 | 하나회 11 期同学 vs 将被清洗的旧将 |
| 权力层 | 谁当事实统帅；事后能否逼崔圭夏追认，把叛乱写成「调查程序」 | 全斗焕 vs 法统指挥链 |

【推断】郑升和若完成对全、卢的调职，하나회 的晋升管道关闭——这是跳船定理的左侧：捍卫旧位置的收益变为负。全的右侧报价是：今晚一起动手，赢了你们进入新 $W$。所以「拉拢」在这里不是请客，是**把死亡威胁改写成共同剩余索取权**。

## 3. 双方联盟资产负债表

### 3.1 全斗焕：小 $W$，节点密度极高

【事实】하나회 约 1963 年由陆军士官学校 11 期（全斗焕、卢泰愚、郑镐溶等）结成私党组织。朴正熙时期其成员超速晋升，并嵌入保安司、特战、首都警备等防政变节点。

【推断】这是预先做好的**团结（长久期）**：身份是同期+私党，支付是晋升特权，不是当晚才发的红包。六句法里真正昂贵、也最能打仗的头寸，全在政变前十年已经建好。

当晚最低获胜节点（Riker：刚好能赢，不必拥有全军）：

| 节点 | 功能 | 六句操作 |
|---|---|---|
| 保安司令部 DSC | 监听军网、反政变职权反装成政变工具 | **利用**制度职权 + **孤立**对方通信 |
| 首都警备 30/33 营 | 汉城城内部队 | **团结**（已是自己人） |
| 特战 1、3、5 旅长（朴熙道、崔世昌、张基梧） | 抗命自己的司令官郑炳宙，把枪口掉转 | **拉拢**（同期/私党身份 + 事后兵权） |
| 第 9 师 29 团（卢泰愚） | 前线师抽部进京 | **团结**（核心自己人） |
| 国防部长卢载铉 Roh Jae-hyun | 先逃到龙山美军基地，回来后下令逮捕郑升和 | **利用**其求生，再收其签字 |
| 崔圭夏 | 起初拒签，既成事实后追认 | 事后 **拉拢/胁迫**，把打击写成程序 |

【事实】海空军未参加叛乱。【推断】这是正确的**放弃**：当晚不需要他们；赢了再 **拉拢** 收编。目标不是朋友最大化，是可供养的获胜联盟。

### 3.2 郑升和 / 张泰玩：大 $S$，空 $W$

【事实】郑升和是参谋总长兼戒严司令，法统上几乎是全军之首。张泰玩是首都警备司令官，职责就是防政变、守汉城。

【推断】他们拥有的是**职务图**，不是**联盟图**。部下中的关键旅长已经用另一套识别函数（하나회 同学）登记过了。张泰玩拒绝叛军招安后，被自己的下属背叛——这是「拉拢失败」的精确定义：你无法给中间派一个比对方更高、且可核验的报价。

【事实】国防部长当晚带全家逃往龙山求美军保护，拒绝对全下令逮捕，反而配合逮捕郑。【推断】跳船定理：部长的物理层利益（活命、避内战、避北韩借口）压过对法统的 L3 忠诚。他不是「坏人」，是 $S$ 里贴现率极高的 swing。

## 4. 六句法对打：同一晚上，两种会计

| 操作 | 全斗焕怎么做 | 郑 / 张怎么做 | 胜负原因 |
|---|---|---|---|
| **团结** | 十年하나회：同期、超速晋升、共同风险 | 靠军纪与职务：便宜，但政变夜贴现为零 | 长久期私党 > 法统口号 |
| **拉拢** | 特战旅长、事后海空军、逼总统追认 | 对全/卢只有调职压力，没有给中间派座位 | 全把对方的 $S$ 买成自己的 $W$ |
| **利用** | 10.26 调查权当逮捕令；美军「不要又一个伊朗」的稳定偏好 | 指望总统批示、美军介入 | 职权与外部否决权都被对方当盾 |
| **放弃** | 不拉全军、不拉海空军、不拉反对党 | 没有主动收缩，幻想「全军应站在法统一边」 | 散沙多数幻觉 |
| **孤立** | 先抓郑，占本部与国防部，监听军网 | 未能切断하나회 横向联络 | 打击前先拆协调网的一方赢 |
| **打击** | 只打三个人：郑升和、张泰玩、郑炳宙 | 张的坦克威胁是 cheap talk：授权未到、部下不跟 | 打击无孤立、无承诺，只改变音量不改变人数 |

【推断】全的打击集合极小，符合 Riker：消灭的是对方 $W$ 的三个锚点，不是「人民的敌人」。张的失败验证六句法自我拆台第 2 条：**没有孤立的打击，敌人集合不减反增——但若你连打击都打不出去，连集合都改写不了。**

【个人判断】全对张泰玩的招安是标准 **拉拢**；张拒绝后进入 **打击**。全付得起这个失败，因为张不是 swing 节点里唯一的首都武力——30/33 营已经在己方。张付不起拒绝后的孤立，因为他的 $W$ 是空的。

## 5. 5 问滤镜（当晚）

1. **利益流向**：剩余索取权从「戒严司令官—法统将领」转到「하나회 小圈子」。现金二次分配发生在 1980 年代新军部—财阀管道，不在 12.12 当夜。
2. **制度几何**：全在向极小 $W$（同期将领）兑现分红：师、军团、保安司、青瓦台。崔圭夏是被事后纳入的合法性贴纸，不是 $W$。
3. **承诺机制**：叛军内部承诺靠共同犯罪（一起绑参谋总长）——这是不可逆抵押。张对部下的承诺是「总统会批、美军会管」——双方都是 cheap talk。
4. **协调阻尼**：防政变的通信中枢在保安司手里。多数派无法同步开火。奥尔森集体行动：分散的「忠于法统」打不过已经串好的少数人。
5. **做功场健康度**：12.12 本身是 L0 再拍卖，不是给 L1 降摩擦。后续 5.17 戒严扩大与光州镇压，是用暴力抽水强行关闭民主化窗口；经济增长那一段要另账（三低景气、出口机器），不能记在政变的道德名下。

## 6. 校准用户命题：「核心能力 = 利益分配 + 拉拢」

【个人判断】**成立，但要加三个约束，否则会学成请客送礼。**

### 6.1 分配的是座位与豁免，且必须可核验

全能拉到特战旅长，是因为报价具体：跟我站队 → 旅/师/未来政权股份；站对面 → 今晚被缴械。郑能给的是「遵守指挥链」，政变夜无法兑现保护。  
【个人判断】**可以没有永恒的敌人，但不能没有可核验的履约。** 张的坦克是不可核验履约。

### 6.2 拉拢服从最低获胜联盟，不是人多

全放弃海空军与大部分野战军，只买节点。张以为首都警备司令官这个职称等于拥有汉城全部枪——职称是 $S$ 门票，不是 $W$ 名单。

### 6.3 拉拢之前是分类；拉拢之外是阻断协调

最高阶动作是改识别函数：部下用「하나회 同学」而不是「司令官命令」来决定开枪。全还垄断了通信，让法统多数无法完成一次共同知识下的反击。  
【个人判断】不会分类、不会切断对方电话的人，利益分配只是发钱，发完仍然会被有节点的人收割。

### 6.4 赢了必须换坐标系（本库清洗专题的接口）

【事实】1980-01 军中大洗牌；1980-05-17 扩大戒严、抓金大中等；光州被镇压。这是夺权后缩 $W$：战时用过的通道（特战旅、戒严）变成执政后的私人物品政权。  
【推断】12.12 的六句法若当成治理宪法，就是本库误区 9（战时动员常态化）。全后来的失败不在当晚不会拉拢，而在把极小 $W$ 的私人物品政权开到社会做功场开始反噬（1987 年跳船）。

## 7. 竞争性解释（必须并列，不把一种写成事实）

**A. 道德 / 军纪**：张泰玩是「真正的军人」，全是叛贼。解释得了评价，解释不了胜负。

**B. 制度职权俘获**：防政变机关（保安司）被政变者掌握，狐狸看鸡窝。强处：解释通信与合法性掩护。弱处：职权本身不会开枪，还需要하나회 把职权变成联盟。

**C. 美军否决权**：卡特政府怕伊朗式崩溃与北韩，选择稳定。强处：解释为什么张指望的外部第三方不出现。弱处：美军没帮全打仗；全是先造成既成事实。

**D. 北韩阴影 / 安全困境**：任何开炮都可能被写成内战邀请金日成。这提高了法统方「打击」的成本，降低了叛军「孤立」的成本。是力学约束，不是全的阴谋。

**E. Riker 最低获胜联盟 + Olson 集体行动**：少数人已协调，多数人未协调。这是本库主解释。

## 8. 压缩版（给下一会话）

1. 政治家的核心能力：**按久期把剩余索取权卖给刚好能赢的节点，并切断对方节点之间的电话。**
2. 12.12：全斗焕 = 预置团结（하나회）+ 拉拢对方旅长 + 利用调查权 + 放弃全军 + 孤立法统 + 定点打击三人。
3. 张泰玩 / 郑升和 = 法统大 $S$、空 $W$；拉拢失败，打击是 cheap talk。
4. 「利益分配」若理解成发钱，会看不懂这晚；应理解成**谁进入下一政权的分水名单**。
5. 电影双雄是记忆锚；分析用历史三方：全 vs 郑升和（制度），全 vs 张/郑炳宙（当晚）。
