# 政治的第一性原理：止掠做功场 × 剩余索取权

- Date: 2026-08-19

- 依赖：`coalition-arithmetic.md`、`urbanization-coalition-momentum.md`；经济学锚见 SESSION §1、§16、§23

## 核心判断

【个人判断】政治的第一性原理不是敌友名单，也不是「制定规则让大家发财」。压缩成一句：

> **把私人互掠的负和均衡，替换成可保护、可征税的正和生产场，并规定这个场上的剩余归谁。**

前半句解释**为什么政治被容忍**（无它则分工、城市、势能都做不成功）。后半句解释**政治一旦存在就在争什么**（水龙头 / 剩余索取权）。六句是后半句的操作手册。用户这次补上的是前半句。两句合在一起才是「全部本质」的最小完备集。

【个人判断】「每个人都比没有政治时更好，只是额度不同，且都觉得符合预期」——前半作为**相对无政府的参与约束**常常成立；作为**对自己创造剩余的公平份额**不成立；「大家都符合预期」不是规律，是合法性成功时的表象。

## 用户命题拆开

| 命题 | 判定 | 校准 |
|---|---|---|
| 无政治则互防、缠斗、掠夺，总收益下降 | 【个人判断】成立 | 霍布斯自然状态 / 科斯摩擦无穷大：交换做不成，城镇化做不成，势能有梯度无介质 |
| 有人制定秩序，换来发展经济的空间，且大于无政治 | 【个人判断】对「场」成立，对「每一个人」不成立 | 场的总剩余上升；被打击/放弃/当燃料的人，相对无政府也可能更差，或只是更好但远低于其边际产出 |
| 所以大家允许政治存在 | 【推断】过强 | 多数人满足的是参与约束，不是契约同意。集体行动成本高，不需要人人允许。暴力专家之间先达成分赃，再向场内收保护费 |
| 分配隐蔽，有人靠近水龙头 | 【个人判断】成立 | 即坎蒂隆路径 + 通道所有权。与本库地租/平台税同构 |
| 智力、信息不同，故抽成不同 | 【推断】部分成立 | 信息差是放大器；更硬的是**位置**：谁写规则、谁先接到信贷、谁占核心土地。智力不是主因 |
| 个体收益大于无政治，额度不同，整体符合预期 | 【个人判断】对照基准被设错了 | 人比较的是无秩序 / 昨天 / 邻居，不是自己做出来的剩余。基准可被叙事设定。揭示偏好（退出、不生育、抗议）说明预期经常没被满足 |

## 四层，不是一层

| 层 | 问题 | 本库已有锚 | 缺了会怎样 |
|---|---|---|---|
| **L0 止掠** | 谁有权使用暴力、谁不许私掠 | 霍布斯；税收是对「暴力合法性与公共秩序」抽税（SESSION §23.6） | 有梯度无介质，功变成热：互防互掠 |
| **L1 做功规则** | 产权、货币、契约、城市、基础设施如何降摩擦 | 科斯、马歇尔集聚、城镇化超导（§23）；势能三要素的「导流与约束」 | 有秩序仍是流寇：护得住、做不出剩余 |
| **L2 剩余索取** | 剩余进谁的账、谁靠近水龙头 | 六句；李嘉图地租；土地财政；三级跳收租 | 只做大饼，联盟裂开，或只清洗不生产 |
| **L3 对照基准** | 人们拿什么当「公平/预期」 | 叙事层；「人民」被写成多数 | 抽成被识别为掠夺 → 要么加打击成本，要么改规则 |

六句 = L2。用户本次 = L0 + 对 L3 的直觉（符合预期）+ 对 L2 隐蔽性的直觉（水龙头）。L1 是本库势能/城镇化已经写过、政治六句跳过的那一层。

【个人判断】**全部本质是 L0→L1→L2→L3 的闭环**，任何单层当本质都会过拟合：只讲六句变成阴谋论；只讲秩序与做大蛋糕变成宣传；只讲预期变成把合法性当成事实。

## 第一性原理：势能语言

本库势能三要素：源泉/梯度、导流与约束、转化。无政治时：

- 人仍想交换、分工、进城（梯度在）
- 介质是互相掠夺和无穷交易费用（约束是负的）
- 做功变成防卫和掠夺，不沉淀为剩余

有政治时：秩序垄断把介质从「互掠」换成「可预期规则」。功才可能变成剩余。然后**谁拥有介质，谁收租**——水龙头不是分配的边角，是导流层的产权。

城镇化是这套原理的最大物理项目：压缩空间阻尼（L1）必须以止掠和产权为前提（L0）；密度变成级差地租（L2）；户籍/学区把「符合预期」写成空间身份（L3）。农民产值翻倍而剩余被抽走，可以同时成立：L1 对他们做功了，L2 没把他们标成团结对象，L3 让对照基准停在「比村里强」。

---

## 「符合预期」的机制，不是道德

【推断】政治能长期抽成而不崩，靠的不是人人算清了社会剩余，而是三道便宜的比较：

1. **对无政府**：只要高于互掠，参与约束就过。这是用户命题的硬核，且通常够用。
2. **对昨天**：增量阶段（城镇化吸人）容易过；存量阶段工资跑不赢地租就会破。
3. **对可见的邻居**：不跟水龙头比，跟同乡、同事比。信息结构本身就是隔离。

【个人判断】「大家都认为符合预期」一旦写成本质，会把 L3 的成功误当成 L0–L2 的真理。L3 失败时政治仍然存在，只是更依赖打击，更贵。

【待验证】生育率、移民、躺平作为揭示偏好，是否系统性地标志「相对昨天」这条约束已经破——需按具体政体回测，不在此下结论。

## 和六句、城镇化的接口

- 六句回答：在 L2，如何保住水龙头、如何决定谁被接到场内。
- 城镇化回答：L1 如何把身体接入高阶生产函数；L2 如何把密度贴现成 70 年地租。
- 本次补上：L0 为什么需要一个能制定规则的主体；L3 为什么不等额抽成仍可运转。
- Olson 固定匪帮：长视界统治者有激励做大 L1 再在 L2 抽税。流寇只做 L2，吃光 L1。这是「允许政治存在」在统治者侧的对应条件。

## 压缩版（给下一会话）

1. 政治存在的下限：止掠，否则势能有梯度无介质。
2. 政治存在的上限：把止掠写成做功规则，并争夺剩余索取权。
3. 人们「允许」的往往是相对无政府更好，不是相对自己创造的剩余更好。
4. 水龙头 = 导流介质的产权；隐蔽性来自对照基准，不只来自智商差。
5. 六句是 L2 手册；全部本质是 L0–L3 闭环。
