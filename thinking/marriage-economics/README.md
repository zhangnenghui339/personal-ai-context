# 婚姻/家庭经济学研究

本目录用于沉淀婚姻、家庭与人口决策的政治经济学分析——把 `thinking/politics/` 与 `thinking/business/` 里已有的模型应用到婚姻/家庭领域，而不是另起一套独立理论。

## 使用边界

- 区分：可验证事实、来源观点、分析推断、价值判断。
- 涉及性别/婚恋相关的论断，优先标注适用条件与时代/群体边界，不把某个历史阶段的均衡写成普遍规律。
- 优先使用经济学/社会学一手文献（学术论文、专著），媒体转述需交叉核对。
- 不保存未经验证的传闻、个人敏感信息。

## 文件结构

- `session.md`：领域会话总览、核心判断（婚姻作为政治经济学结合体）与卫星文件索引入口。
- `topics/`：按具体议题沉淀深度专题：
  - `becker-treatise-on-family.md`：贝克尔《家庭论》核心论点与标志性概念（分工/选型婚配/坏孩子定理/数量质量替代）。
  - `marriage-as-political-economy.md`：婚姻作为政治经济学结合体的模型对照，及性/颜值资源变量的对称性问题。
  - `declining-marriage-rate.md`：结婚率下降与不婚现象的五条机制。
- `sources.md`：长期使用的权威来源与可靠性说明。
