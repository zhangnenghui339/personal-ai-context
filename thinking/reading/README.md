# 读书研究

本目录用于沉淀经典与非虚构著作的精读笔记，以及由书引发的跨书长期思考。

与顶层 `books/` 的分工：

- 顶层 `books/reading-list.md`：书架层 —— 读什么、状态、为什么读、一句话索引。
- 本目录：认知层 —— 逐书精读提炼 + 跨书主题综合。
- `books/reading-list.md` 的「笔记」列链接到 `thinking/reading/notes/<book>.md`。

## 使用边界

- 区分：原文引文、通行释义、个人判断、假设。
- 引原文标章节；用译本 / 转述时注明版本。
- 不把整本电子书放进仓库（见根 `README.md`），只留引文、提炼与个人笔记。
- 跨书对照只做「意思是否同构」的判断，不强行凑字面。

## 文件结构

- `session.md`：读书领域会话总览、常用分析框架与卫星文件索引。
- `sources.md`：书目、版本 / 译本、对应腾讯文档思维导图链接与可靠性说明。
- `notes/`：逐书精读笔记，一本一文件（摘录 + 提炼）。
- `topics/`：跨书 / 主题思考。
  - `potential-energy-across-classics.md`：商业「势能」框架 × 七部经典的逐条对照（孙子 / 纳瓦尔 / 鬼谷子 / 管子 / 决策思维 / 道德经 / 韩非子 / 思维模型）。
  - `weakness-as-application.md`：「弱者道之用」单独展开（字义 + 势能视角 + 五个可操作面 + 现代商业案例）。
  - `first-mover-vs-timing-window.md`：「不敢为天下先」与「趋势冒头就抢占位」是否矛盾。
