## 给下一会话的 AI

用户在完善「创业机会发现」模型。原模型是：不断尝试 → 局部供需失衡 → 低成本交易验证 → 信号 → 加码 → 修正。用户补了 Distribution 和套利结构化，并认为早期可抽象为：发现失衡 → 分发入口 → 第一次套利 → UE → 放大 → 结构化 → 长期资产。

已修正：这条直线是成功叙事，不是搜索算法。用下面的工作模型。用户默认中文；SEO/术语保留英文。先给结论，不讲基础概念。

## 工作模型

### 三层（升维路径）

用户原先只问产品（帮谁解决什么）。补上分发是第二层。再上一层是权力，不是又一个获客技巧。

| 层 | 问题 | 幻觉 |
|---|---|---|
| 1. 创造剩余 | 对谁有用 | 有用就会有人来 |
| 2. 接触剩余 | 谁能看见、买到 | 投放 = 拥有分发 |
| 3. 占有剩余 | 谁有权分配注意力/交易；利润归谁 | 租来的流量是自己的资产 |

底：剩余被创造后，由谁、按什么规则、分配给谁。  
起步需要分发**入口**（借势）。终局争夺分发**权**（卡口）。不要求第一天拥有权。

刘炽平默认站第 3 层（腾讯已有关系链，投资让别人在门里摆摊）。创始人只有产品思维时模仿他会空转。

### 机会方程与两层过程

```
机会 = Gap(Spread) × 分发入口(Access) × 可占有性 × 可交易性
```

任一项为 0 则不是生意。起点可以是失衡、分发或能力/成本差，关键是匹配。

- **发现循环：** 尝试 → 匹配「差 × 能碰到付钱的人的门」→ 最小真实交易。
- **捕获阶梯：** 第一次套利 → 诚实 UE → 窗口内放大 → 把重复套利变成资产 → 用资产吃下一层差。

套利 = 经济体给发现者的非稀释融资（Hobart）。对活过早期经常是主因。对终端价值通常不是充分条件。停在套利层可以很赚钱，很少成为终局公司。好 UE ≠ 已结构化。

口诀：套利是启动贷款。贷款到期，看房子还在不在。

### 四层洼地（扫描差的种类，不是时序）

时空 / 阶层 / 介质 / 技术。技术差 = 最贵工序便宜一个数量级，不是「发明了科技」。2026-08-25 五案回测：Google 最接近纯技术差；App Store/移动互联网主引擎含介质；Uber 主引擎是时空（黑车远早于 App）。规则空窗不升格为第五洼地。详见 `five-cases-tech-arb-level-backtest.md`。

### 读创业史四问（替代「它做对了什么产品」）

1. 它最初借了谁的势？
2. 它从哪里拿到第一批客户？（最常被省略；只复制产品就是丢掉这一问）
3. 当时存在什么暂时没被抹平的 Gap？
4. 它最后把借来的 Distribution/Gap 转化成了什么自有资产？

第二问答不出「第一千个人从哪扇门进」，案例不能指导行动。真入口经常是对手或邻接平台已经标好的身份图（email 只是指针名）。外面不说，因为一说窗口就关。

### 不对称行为

不在同一条街比勤快。在对方看不见、看轻、或动不了的维度先成交：信息、解释、分发、现金、计费。

## Hobart 压缩（「带基础设施的套利」是本库转述）

原标题：*Arbs Close, Infrastructure Remains*（The Diff, 2025-05-12）。作者：*The Diff* / *Capital Gains*，交易研究背景，不是操盘明星。

1. 创业与套利表面上相反，经常叠在一起。早期像套利，后期必须改造输入。
2. 可利用的差 = 非稀释融资。
3. 一眼能看见的差被打光。继续吃差靠识别信号 + 执行的基础设施。吸尘器比硬币值钱。
4. 公司变得 less arb-y。不能永远买 X 稍贵卖出。
5. 套利不能无限规模化；有时能把交易做成公司。看差关掉后管子、仓库、习惯、数据还在不在。
6. 监管套利有保质期。做成它所需的最小系统，事后往往够支撑更受监管的正经生意。钻空子 ≠ 立新产权（创造一种新权利并对它征税；先增长再补手续）。
7. 平台终局对管道上的套利收税；可规模化厚利在平台眼里就是套利。
8. 经济利润靠信息差。消费互联网像麦克斯韦妖：收费做介绍，不种粮食。

分发三句（*Owning Distribution*, 2024）：

- 做出人们喜欢的产品 ≠ 因为这个产品人们喜欢你这家公司（最后一碰）。
- 短期抢所有分发；饱和且管道开始跟你抢时，少付钱。
- 拥有分发重要，但先理解分发往哪走，才知道什么值得拥有（收费站值钱，前提是车以后还走这条路）。

## 案例（四问口径）

### QQ

- 势：ICQ；深圳电信带宽/服务器；网吧；移动梦网计费。用户说的「QQ IPS」读作 ISP/运营商管道。
- 第一批：聊天室截流、杂志、网吧预装、比华南竞品更稳的口碑。
- Gap：公共聊天室不能私聊留联系；有用户不会收费。
- 资产：关系链。短信/ISP 会关。

### Airbnb

- 势：大会酒店短缺；Craigslist 意图流。
- 第一批：气垫床三人是起源。放量两条桥——向外发帖截需求；向内（少说）把对手挂房的人当高意图供给名单，用联系方式迁进 Airbnb。
- Gap：发现已被对手做完，闭环（信任/支付/摄影）极差。
- 资产：评价、保险、密度、品牌。指针管道必须在关掉前迁完。

### 拼多多

- 势：微信关系链/小程序；腾讯；下沉价格带。
- 第一批：熟人拉进拼团/砍价，不是搜索。
- Gap：会买不会搜；工厂有货没有便宜获客。
- 资产：自有 App、供应链、广告、Temu。

### 美团

- 势：Groupon；千团资本；地推组织。
- 第一批：地推核销，不是商店自然量。
- Gap：本地闲置产能；行业 UE 很差。
- 资产：外卖履约网、到店密度。抄页面的人死在获客和核销。

### 紫鸟浏览器

- 势：平台一店一主体制造多开；跨境社群；创始人当过卖家。
- 第一批：卖家圈子。卖铲给正在做规则差的人。
- Gap：多开 vs 风控；中文工具差。
- 资产：预付 SaaS、权限协作。好 UE ≠ 已结构化。防关联随政策均值回归。

### 李嘉诚（对照，不是互联网产品）

- 1967 前后：解释差 + 塑胶花现金，恐慌中买地 → 土地储备。
- 1977 地铁上盖：知道地铁必须付现金且缺现金，标书对准约束 → 核心上盖。
- 之后：港口 = 物理介绍权。

### 其他锚点

- Amazon：图书长尾 + 联盟 + 现金周期/税差 → 飞轮、3P、物流、AWS（多层叠加）。
- Google：质量差先于广告；产品即分发；终局锁默认位/Chrome/Android。部分反驳「先分发再套利」的线性顺序。
- PayPal×eBay、QQ×聊天室、美团×店址电话、紫鸟×卖家社群：与 Airbnb 向内同一机制——已经用笨办法做过的名单。

## 找机会时怎么用

先写第二问：第一千个付钱的人具体从哪扇门进。门还在、过路费未涨，才借势。

七问（通不过就停）：差是什么、为何没闭合；入口成本是否低于能分到的差；本周能否真实成交；诚实 UE；百人复制还剩什么；每笔交易沉淀了什么；价差归零是否还有生意。

1–4 过、5–7 弱 → 收割。1–4 且 6–7 强 → 按公司做。1–3 过、4 不过 → 换入口或削履约，先别加功能。

对手身份图三条：名单现在能否碰到；迁完前窗口会否关上；迁完有无自有资产。后两条不过 = 收割。

## 术语

- **UE：** 一个客户/一单/一台订阅是否划算（含获客、履约、风险、时间）。紫鸟预付费、高毛利、无应收 = 好 UE。
- **分发入口 vs 分发权：** 碰到人 vs 决定别人碰到谁。
- **麦克斯韦妖：** 站在门边给供需分类，收费做介绍。
