# 商业思考

本目录沉淀商业与产业分析的长期研究：势能与套利母模型、分发与流量、创业机会发现、创始人与投资决策规律、国家级战略的经济学拆解、思维透镜与案例库。

## 使用边界

- 区分：可验证事实、来源观点、分析推断、价值判断。
- 涉及时效性事实（市场数据、融资、装机量等）时，记录日期与来源。
- 分析创业史时抛弃道德评价；规则差、对手名单等只当窗口与风险变量，不写采集 / 绕过 / 群发等可复现步骤。
- 新结论与旧记录冲突时不静默覆盖，注明日期、证据与被替代结论。
- 会话简报（`session/`）是提炼后的入口，不是聊天记录。
