# 普通人 vs 顶级分析师：经济学 / 投资学里常见的「认知算法」差异

- Date: 2026-09-01
- Status: working note
- Scope: 把同一个事实代进不同计算方式所产生的系统性分歧,压缩成 18 条配对对照(普通人的算法 vs 顶级分析师的算法)。差别通常不在「知道更多」,而在**用了不同的公式 / 启发式**。
- 定位:这是 `[[contrarian-decision-patterns]]` 末尾注明「留待展开成独立文件」的那一版——把「大众怎么想 vs 他怎么想」逐条落盘。前者是人物清单,本篇是算法清单。
- 关联文件:`[[contrarian-decision-patterns]]`、`[[vc-power-law-decision-rules]]`、`[[bezos-market-leadership-window-terminal-value]]`、`[[bezos-core-principles]]`、`[[beyond-economics-meta-model]]`、`[[macro-to-micro-nested-lenses]]`、`[[executive-startup-dilemma-and-base-rates]]`
- 使用边界:条目是分析推断与方法论归纳,不是可验证事实;人名只标代表倾向,非完整名单。

---

## 一句话总纲

> 普通人算 **均值、当期、名义、静态、结果**;
> 顶级分析师算 **尾部、终值、实际、博弈、过程**。

下面 5 组、18 条是这句话的展开。

---

## A. 估值与终值

### A1. 终端价值(terminal value)
- **普通人**:当期利润 × 一个固定倍数;线性外推明年 EPS;把「现在 P/E 高」直接读成「贵」。
- **顶级分析师**:分阶段 DCF,估值的 70%+ 来自终值——所以真正的赌注是 **10 年后的竞争结构**,不是明年利润。增长引擎 = 再投资率 × 再投资的边际回报率,并要问这个回报能维持多少年(competitive advantage period / fade rate)。
- **本质**:估值是对「护城河存续期」的定价,不是对当期盈利的定价。(详见 `[[bezos-market-leadership-window-terminal-value]]`)

### A2. 收益口径(Bezos 的算法)
- **普通人**:看每股收益 / 净利润 / 好看的 GAAP 报表。
- **顶级分析师**:看 **自由现金流 / 股**(owner earnings)。为了长期现金流,可以主动牺牲当期利润、主动难看报表;折旧、股权激励、营运资本变化都要还原。
- **本质**:会计利润是观点,现金是事实。

### A3. 增长的价值
- **普通人**:高增长 = 好资产;增长率数字越大越买。
- **顶级分析师**:增长必须乘以「边际再投资回报率」和「能维持多久」。**没有护城河的增长是价值毁灭**——要持续烧钱,而回报最终回落到资本成本。区分规模经济 / 网络效应 / 转换成本 / 无形资产四类护城河。
- **本质**:增长是杠杆,护城河决定它放大的是价值还是亏损。

### A4. 市场规模(TAM)
- **普通人**:自上而下——「占 X 亿市场的 1%」;把现有品类大小当上限。
- **顶级分析师**:自下而上——单位经济 × 可触达客户 × 频次。更关键:**成本曲线下降会创造原本不存在的品类**,盯着不变的东西(更便宜、更快、更多选择)+ 沿成本结构倒推新需求。(详见 `[[bezos-wedge-selection-funnel]]`)
- **本质**:大机会往往「还没被正确定价」,因为它所在的品类还没出现。

## B. 概率与不确定性

### B1. 期望值 / 幂律
- **普通人**:用「均值」和「最可能情况」思考,直觉是正态分布;追求高胜率,规避看起来会亏的赌注。
- **顶级分析师**:用**分布的尾部**思考。凸性:下行封顶 1x、上行不封顶。胜率不重要,**赔率 × 命中时的幅度**(棒球里的 slugging 而非 batting average)才重要;一笔 100x 覆盖 10 笔归零,主动接受 70% 失败率去换尾部暴露。
- **本质**:优化分布的形状,不优化分布的中位数。(详见 `[[vc-power-law-decision-rules]]`)

### B2. 非遍历性 / 毁灭风险(ergodicity)
- **普通人**:+EV 的事就该做(集合平均);把「破产」当成一次普通的负结果。
- **顶级分析师**:一个人破产一次就永久出局,享受不到平均数(时间平均 ≠ 集合平均)。**第一原则是「绝不归零」**,而非「期望利润最大化」;先排除毁灭路径,再谈优化。
- **本质**:能重复玩的游戏才适用期望值;不能重复的,先保命。(详见 `[[beyond-economics-meta-model]]` 盲区一)

### B3. 概率的本质
- **普通人**:频率派直觉,等可能;「没见过」= 「不会发生」;被生动故事覆盖基础比率(可得性启发)。
- **顶级分析师**:贝叶斯——先验 + 新证据持续更新。区分「我不知道」(认知不确定,可缩小)和「本质随机」(aleatory,不可缩小);要求**校准**——说 70% 就该 70% 命中;事前写下「什么证据会证伪我」。
- **本质**:概率是信念的强度 + 更新规则,不是「五五开」的口头禅。

### B4. 风险的定义
- **普通人**:风险 = 波动率 / 会不会下跌 / 别人怎么看我;用最大回撤衡量。
- **顶级分析师**:风险 = **永久性资本损失的概率 × 幅度**。波动是买入机会不是风险;真正的风险是杠杆、流动性错配、单点依赖、论点错误。用安全边际吸收估值误差。
- **本质**:风险是「本金回不来」,不是「报价在跳」。

### B5. 基础比率与 regime
- **普通人**:用近期经验外推(近因偏差);没经历过的 regime 当它不存在(零利率结束、2008、疫情)。
- **顶级分析师**:先套长历史的基础比率(class 视角),再叠加个案调整;主动识别 **regime change**——利率、流动性、监管、技术函数的断点会让历史均值整体失效。
- **本质**:先问「这类事情通常怎么收场」,再问「这次哪里不一样」。(详见 `[[executive-startup-dilemma-and-base-rates]]`)

## C. 结构与博弈

### C1. 均衡 vs 二阶思维
- **普通人**:静态——「现在贵还是便宜」;默认别人会继续做现在做的事。
- **顶级分析师**:价格已经包含了共识,**我的边际信息 / 边际视角是什么**?对手会怎么反应(平台征税、Sherlocking、新玩家进入)?反身性——价格本身会改变基本面。
- **本质**:市场是对手方的集合,不是一个可以静态称重的物体。

### C2. 非共识且正确
- **普通人**:「我看对了」就满足;或者反过来,为了不同而不同。
- **顶级分析师**:**只有「非共识 且 正确」才有超额回报**。共识且正确 = 已在价格里;非共识且错误 = 亏钱。下注前先定位:共识错在哪、我凭什么知道。
- **本质**:超额收益来自「预期差」被修正,不来自「事实」本身。

### C3. 十年后的需求
- **普通人**:外推当前热点,问「什么会变」。
- **顶级分析师**:反过来问「**什么不会变**」,把战略建在不变量上;技术断裂时问「哪些约束被解除了、新约束是什么」。
- **本质**:把可预测的慢变量当地基,把不可预测的快变量当期权。(详见 `[[detecting-level-1-technological-discontinuity]]`)

### C4. 相关 vs 因果
- **普通人**:相关当因果;线性单因;忽略混杂变量。
- **顶级分析师**:找机制;用自然实验 / 反事实;主动搜**幸存者偏差**(只看到活下来的基金和公司);区分样本内拟合和样本外表现。
- **本质**:先证明「是它导致的」,再谈能不能复制。

### C5. 信息的边际价值(edge)
- **普通人**:消费公开新闻当 edge;「信息越多 → 决策越好」。
- **顶级分析师**:edge = **专有观测点 / 处理方式差异 / 时间结构差异**(能等别人不能等)。公开信息已在价格里;说不出「这笔交易我为什么比对手强」,就不下注。
- **本质**:优势必须可名状;名状不出来的,你就是对手方的流动性。

## D. 决策与仓位

### D1. 沉没成本 / 卖出触发
- **普通人**:「已经投了这么多,再等等」;用买入价锚定,「回本就卖」。
- **顶级分析师**:当前持仓 = 用今天的市值重新做一次的买入决策。**卖出触发是「论点变了」,不是「涨了 3 倍」或「跌回成本」**。
- **本质**:成本价是历史,和「现在该不该持有」无关。(详见 `[[vc-power-law-decision-rules]]` 的「不封顶 vs 该不该卖」)

### D2. 边际 vs 平均
- **普通人**:用平均成本 / 平均值决策(「平均每个客户赚 X」)。
- **顶级分析师**:只看边际——下一个客户的增量收入 vs 增量成本;固定成本已沉没。边际成本趋零的生意有截然不同的终局。
- **本质**:决策发生在边际上,不发生在平均值上。

### D3. 仓位规模(sizing)
- **普通人**:平均下注 / 凭信心下注;或全押;亏了就加仓摊薄成本。
- **顶级分析师**:按边际优势和赔率定规模(分数 Kelly);单笔风险预算封顶。赢面大敢重仓、模糊时小仓;**只因「论点更强」加仓,不因「跌了」加仓**。
- **本质**:对的方向 + 错的仓位 = 还是输;下注大小本身是独立决策。

### D4. 集中 vs 分散
- **普通人**:分散总是更安全;持仓越多越稳。
- **顶级分析师**:**下行已封顶时,集中在少数高信念标的**;过度分散是「无知的对冲」,会把 outlier 的贡献稀释掉。分散用在「无法识别优势」时,不是默认档。
- **本质**:分散是承认自己没有 edge 的姿态,有 edge 就该集中。(见 `[[contrarian-decision-patterns]]` 第 2 条)

### D5. 结果归因(resulting)
- **普通人**:结果导向——赚了就是对的,运气当能力,亏了才复盘。
- **顶级分析师**:过程导向——决策质量与结果分开评。写事前决策日志锁定理由;区分 process luck 和 skill;看大样本不看单次。
- **本质**:一次好结果可能来自坏决策 + 好运;要评的是决策。

### D6. via negativa / 说不
- **普通人**:靠「多做一件对的事」改善结果;清单越加越长。
- **顶级分析师**:靠**移除错误、少犯蠢**改善结果(Munger 的 inversion);先问「怎样必输」再倒过来避开;stop-doing list 优先于 to-do list。
- **本质**:长期收益更多来自没踩的坑,而非多抓的机会。

## E. 宏观与度量

### E1. 实际 vs 名义
- **普通人**:名义思考——工资涨了就是变富;对「通胀侵蚀名义债务」没有体感。
- **顶级分析师**:一切转实际。通胀是对现金和名义债权人的税;看资产久期与利率敏感度;**定价权 = 能否把通胀转嫁给客户**。
- **本质**:数字变大不等于购买力变大;先除掉通胀再比较。

### E2. 时间尺度 / time arbitrage
- **普通人**:以月 / 季度为单位;高估一年能做的、低估十年能做的;对复利的后段爆发没有直觉。
- **顶级分析师**:以 5–10 年为决策单位,把别人的短期主义当**结构性套利**(愿意承受三年不涨去换第五年的重估);知道复利收益大部分在后段。
- **本质**:时间套利的对手方,是所有被季度考核绑住的人。

### E3. 机会成本
- **普通人**:只算显性支出;「反正闲着也是闲着」。
- **顶级分析师**:资本 + 注意力 + 时间都是稀缺且可配置的;「做 A」= 「放弃当期最优的 B」;没有免费的持有,也没有免费的观望。
- **本质**:每个「是」都是对其它所有选项的「否」。

## 怎么用这张表

1. **自检**:任何一个判断落地前,过一遍——我现在用的是普通人算法还是分析师算法?最常见的滑落点是 B1(用均值想幂律)、D1(用成本价想卖出)、B4(用波动想风险)。
2. **拆分歧**:和别人观点不一致时,先定位是「事实分歧」还是「算法分歧」。多数长期分歧是后者——对方在用不同的公式,不是掌握了不同的数据。
3. **不是全都要切换**:E1 / E2 这类在个人小决策里性价比低;A / B 组在任何有下行风险的重大决策里都值得强制走一遍。
