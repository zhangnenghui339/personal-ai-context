## 核心结论

「从哪里赚钱」和 Bezos 的方法不对立，是**顺序**不同：

- 多数人：选品类（我懂 / 我喜欢 / 看着赚钱）→ 再想怎么做。
- Bezos：先确认**基础设施级相变** → 用新成本结构**倒推**哪个存量品类被重估幅度最大 → 品类只是 wedge（切入口 / 期权），不是商业本质。赚钱是结果，不是入口筛选器。

> Internet 出现 → 新分发基础设施 → 哪个旧行业最容易被重新定价 → Books

当当抄的是这条链**可观察的末端**（书 → 百货 → marketplace），没抄**产生这条链的东西**。京东抄对了一层（体验 → 自建物流 → 履约飞轮），但 Amazon 还多一层「基础设施发生器」（把内部成本中心逐个产品化：Marketplace / FBA / Prime / AWS / Ads）。一句话：**当当学到商品，京东学到基础设施，Bezos 构建的是基础设施发生器。** 底层不可见（在渠道 / 基础设施层、在 GMV 数据出来之前），表层可抄，所以模仿者只拿到 what，没拿到 why 和 how it compounds。

## 五层漏斗

### Layer 0 — 确认是「基础设施级相变」，不是应用层爆款

判据：变的是**分发 / 交易 / 计算的底层成本结构**，不是某个产品变好。信号四特征——

- 出现在商业模式成熟之前（1994 年电商销售额几乎为零）
- 在渠道 / 基础设施层，不在应用层
- 增长是**数量级**，不是百分比（Web 使用量 ~2,300%/年）
- 一旦成立会横向外溢，同时重塑多个行业

用先行指标（渠道渗透率当市场规模的代理变量），不等销售数据。两个陷阱：把热门**产品**当相变（应用层噪声）；把线性当指数。先过 `structural-migration-vs-noise.md` 的 5 问。

### Layer 1 — 用新成本结构倒推「被重估幅度最大的存量品类」

问法转换：不是「我想卖什么」，是「**新成本结构对哪个存量品类的改造幅度最大**」。
先列新范式打穿了哪些成本项：

- 互联网 vs 实体零售：物理货架成本、选品 / 库存成本、地理触达成本、信息（搜索 / 比价）成本
- AI vs 旧生产函数：认知劳动成本、试错 / 迭代成本、集成与切换成本、长尾服务的边际成本、专业知识的稀缺性

然后对每个候选品类按 Layer 2 打分——**先建候选集、再用同一套维度筛选**，「灵光一现选了书」是结果叙事，不是方法（Bezos 据传列了约 20 个品类）。

### Layer 2 — wedge 的结构条件（多个维度同时成立才入选）

| 维度 | books 为什么成立 | AI 版怎么问 |
|---|---|---|
| 供给端集中、易接入 | Ingram / Baker & Taylor 一次接入拿全书目 | 供给 / 数据源是否集中可获取 |
| 高度标准化、机器可处理 | ISBN 全球唯一编码，天然结构化 | 输出可被机器生成**且对错可验证** |
| 信任 / 试错成本低 | 书不用试用，退货率低 | 错了代价小、且容易被发现 |
| 旧渠道有**硬**瓶颈 | 最大实体书店约 10 万 SKU，在版书 150 万+ | 旧世界是**结构性做不到**，不是「能更好」 |
| 扩容对用户有真实价值 | 长尾书需求真实存在，实体店满足不了 | 长尾需求真实且旧世界满足不了 |
| 单位经济学小规模就成立 | 单价适中、复购频次可观 | 客单价 / 复购能覆盖获客 + 交付 |
| （新范式特有）数据 / 工作流私有沉淀 | —— | 干得越多越有专有资产，而不是在喂平台 / 模型厂商 |

books 是少数几个上述维度**全中**的品类。音乐 CD 挂在「供给被唱片公司卡授权、单价低」；服装挂在「非标、要试穿、退货率高」。

### Layer 3 — 把 wedge 当期权，不是终局

进入 wedge 时就要想清楚：它帮我积累什么**可迁移能力**（用户关系、交付 / 履约网络、专有数据、品牌信任、开发者生态）。wedge 的结构优势会随横向扩张下降（books → 百货：SKU 复杂度、库存风险陡增，物流成为竞争核心——当当的教训），所以要在优势还在时，把套利收益修成关不掉的基础设施。
定价用带残值的期望值：

`Adjusted EV = P(success) × Upside − P(failure) × (Downside − 残值)`

偏好残值高的方向：API / marketplace / 交易图谱 > 纯套壳 App > 一次性交付。

### Layer 4 — 选中之后还要过三道闸

1. **幂律**：Downside 可控（`Max Loss << 生存资本`），Upside 不封顶（要 1→100/1000，不是 100→120）。
2. **窗口期**：巨头完成组织动员前你有多久？窗口关闭不受你意志控制；AI 里窗口以**月**计（`bezos-market-leadership-window-terminal-value.md`）。
3. **可占有性**：赢了之后利润会不会被平台 / 模型厂商 / 模仿者零成本抢走。判据 = `hobart-arbitrage-infrastructure.md`：补贴退潮后，钱变成的东西能不能被别人零成本抢走。

## 另一根轴：把产品建在「10 年不变」的绝对需求上

> 「常有人问我：未来 10 年什么会改变？很少有人问我：未来 10 年什么不会变？」——战略要建在不变的东西上。

漏斗 Layer 0–1 回答「选哪个品类」；这根轴回答「在品类里往**哪个矢量**建产品」。

**电商的三个不变绝对需求**：更低的价格、更快的配送、无限丰富的选择。没有哪个客户会在 10 年后反过来说「我希望更贵一点、更慢一点、选择更少一点」。

- 把产品 / 基础设施建在**不变需求的矢量**上 → 每一年的投入都在同一方向复利，代码和基建不过时，反而随规模摊薄、越用越强（飞轮）。
- 建在**会变的东西**上（某个 UI 潮流、某个平台当期的政策红利、某一代模型的特定怪癖）→ 基建是负债，风向一转就减记。

**怎么判断一个领域的「不变需求」**：问「10 年后客户会不会反过来要它的反面？」——能反过来的是**偏好**（会变），不能反过来的是**绝对需求**（不变）。搜索：没人要更不相关、更慢的结果；云：没人要更不可靠、更贵的算力。

**AI 版的不变绝对需求**：更准（少幻觉）、更快、更便宜的 token、更长且可靠的上下文、更强的隐私 / 可控。围绕这些建的东西不会因为模型换代而过时；围绕「某个 wrapper 技巧 / 某代模型的特定行为」建的会。

**和 Layer 4 可占有性的关系**：在不变需求方向上的持续投入，正是「补贴退潮后仍留下、别人零成本抢不走」的那类基建（`hobart-arbitrage-infrastructure.md`：Arbs close, infrastructure remains）。押不变，是让 Layer 3 的「可迁移能力」真的可迁移的前提。

## 「旧世界 → 新世界改变巨大」这个直觉的修正

方向对，但「改变巨大」必须落到**可判断的量**，否则是空的：

- 改造幅度 = f(旧世界的结构约束有多硬, 新范式把哪个成本项打穿了几个数量级)。books 成立是因为「物理货架 10 万上限」是**硬约束**，线上是 10x+。「体验提升 20%」不算。
- **必要不充分**，两个反例：
  1. 改变巨大但你吃不到——差太薄、太快、被平台内化（`hobart-arbitrage-infrastructure.md`：看见 ≠ 吃到）。
  2. 改变巨大但没人为它多付钱——成本坍塌时供给同时暴增，价格砸向边际成本，消费者剩余全归用户，生产者利润为零（`value-and-potential-energy-archetypes.md` 价值三元论）。
- 完整问法接 `ai-shift-opportunity-checklist.md` 四层：结构性迁移还是噪声 → 势差来源命中哪几条 → 势能形态是相变 / 卡口 / 黑洞 → 窗口关闭前沉淀成什么。

## 2026 落点

找「旧世界**必须**靠一批专业人力、工序**高度标准化且对错可验证**、且**数据 / 工作流能私有沉淀**」的存量品类当 wedge；避开纯套壳——差会被模型厂商一次更新抹平。
2026 的等价观测点（对应 1994 年的「Web 使用量增长」）：AI 使用渗透率、Agent 调用量、GEO 引用流量 vs Search、巨头 CapEx 落点、GitHub star / API 调用增长、按技能的招聘岗位增长。诚实提醒：1994 年的信号极稀缺且极大，2026 年更碎片、噪声更大 → 更多机会来自**垂直领域的小规模相变**，竞争优势越来越依赖**观测点本身的专有性**。

## 一句压缩

**先认相变、用成本结构倒推品类，再把产品建在 10 年不变的绝对需求上；品类只是买一个「进入自我强化结构」的期权，选的当下就要想清楚它替你攒下什么关不掉的东西。**
