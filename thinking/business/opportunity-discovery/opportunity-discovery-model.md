# 创业机会发现：失衡 × 分发 × 结构化

- Date: 2026-08-13
- Status: working model
- Scope: 创业早期如何发现、验证、放大机会；用于向前搜索，而不是给成功公司写起源神话
- 替代：原模型「不断尝试 → 局部供需失衡 → 低成本交易验证 → 真实信号 → 加码 → 修正」

## 结论

用户补上的两环——**Distribution** 和 **套利结构化**——是对的。但把早期创业写成一条直线：

> 发现失衡 → 找到分发入口 → 第一次套利 → 验证 Unit Economics → 放大套利 → 将套利结构化 → 沉淀长期资产

会把**搜索过程**和**价值捕获过程**叠在一起，变成成功案例的事后叙事。

可执行版本拆成两层：

1. **发现循环**（怎么找）：多入口并行，核心是把「某种差」和「能碰到付钱的人的入口」匹配上，用真实交易检验。
2. **捕获阶梯**（怎么占住）：第一次套利 → 诚实 UE → 在价差关闭前放大 → 把重复套利变成资产 → 用资产去吃下一层失衡。

一句话：

> 早期创业不是「发现需求」，而是发现**尚未被充分定价的差**，找到**利用这个差的廉价入口**，用交易证明它能赚钱，再赶在差被抹平之前，把交易沉淀成别人抄不走、或抄了也追不上的结构。

关于「抛弃道德评价，套利是不是很多企业最终成功的关键因素」：

- **对活过早期、拿到第一笔非稀释现金流、摸清真实需求：是，而且经常是主因。**
- **对终端价值和持续超额利润：套利本身通常不是。** 最终留下的是结构化之后的资产（分发所有权、成本曲线、网络、品牌、数据、牌照、标准）。
- 更精确：套利是市场给先行者的**非稀释融资 + 学习机制**；结构化才是**价值捕获机制**。两者都关键，但处在不同阶段。停在套利层的公司可以很赚钱，很少成为「最终成功」的那一类。

2026-08-13 补丁：从「只看产品」到「补上分发」是升维；再上一层不是又一个营销技巧，而是**分发权 / 卡口 / 剩余索取权**。创业起步需要的是分发**入口**（借势）；终局争夺的是分发**权利**（谁有权决定流量给谁、交易怎么发生、利润留在谁手里）。两者不要混。

## 0. 三层，不是底层只有一层

「产品帮谁解决什么问题」是第一层，必要，但不是商业现实的底。补上分发是第二层。再升一维，看到的是权力，不是又一个获客渠道。

| 层 | 问题 | 你在做什么 | 常见幻觉 |
|---|---|---|---|
| 1. 创造剩余 | 对谁有用？ | 做产品 | 有用就会有人来 |
| 2. 接触剩余 | 谁能看见、买到？ | 找分发入口 | 投放/增长等于拥有分发 |
| 3. 占有剩余 | 谁有权分配注意力、交易、准入？利润归谁？ | 争卡口，或确认自己只是租管道 | 把租来的流量当成自己的资产 |

商业的底不是「好产品」，也不是「有渠道」。底是：**剩余被创造出来之后，由谁、按什么规则、分配给谁。** 产品创造剩余；分发让剩余碰上付钱的人；分发权决定剩余最终停在哪。

对创业者的操作含义：

- 早期：你几乎不可能拥有第 3 层。正确动作是租用或寄生第 3 层持有者的管道（微信、Google、亚马逊、苹果、抖音、地推组织、行业协会），完成第 1–2 层的匹配和第一笔套利。
- 中期：判断管道主人会不会把你抽干（抽成、限流、自营跟卖、改算法）。这就是可占有性。
- 终局：要么自己变成卡口（腾讯关系链、Google 搜索框、Amazon 物流+Buy Box、苹果装机权），要么把客户关系迁到自有资产上，使离开原管道后生意还在。

所以第 4 问的准确答案是：**真实世界需要分发，但不要求你从第一天拥有分发权。** 需要的是廉价入口；想留下超额利润，才需要权利或等价物（切换成本、密度、品牌、牌照）。

刘炽平默认站在第 3 层看：腾讯已有社交图和支付的分配权，投资是把「做不好的垂直」外包，同时让被投公司来租管道。他不会用「套利」这个词，但行为是：守住卡口，把第 1–2 层交给别人，抽一小部分。创始人若只有产品思维，直接模仿他会空转——你还没有可出租的管。

读创业史不要问「它做对了什么产品」，改问四问：借了谁的势；第一批客户从哪来；当时没被抹平的 Gap；借来的 Distribution/Gap 转化成什么自有资产。第二问最常被省略，也是只复制产品经常失败的原因。五案见 `thinking/business/opportunity-discovery/four-questions-five-products.md`。

## 1. 原模型缺什么

原模型抓住了奥地利学派的核心：市场不均衡，创业者靠警觉和试错发现局部失衡，用最小交易验证。这仍然成立。

它漏了三件会直接改变搜索策略的事：

| 缺口 | 为什么致命 |
|---|---|
| 分发 | 失衡可以存在很久却赚不到钱。没有廉价触达，「需求」只是观察，不是生意。 |
| 可占有性 | 价差可能被平台、渠道、监管或模仿者立刻抽走。能看见 ≠ 能留下。 |
| 结构化 | 纯套利的均衡利润趋近于「做这件事的时间成本」。不做结构，规模越大，差越小。 |

用户补的 Distribution 和结构化，对应表里前两行和第三行。还缺一个操作变量：**均值回归速度**——这个差多久会被竞争、算法、监管或资本抹平。放大必须发生在窗口内；结构化必须快过窗口关闭。

## 2. 经济学上，创业早期到底在做什么

已验证的理论锚点（不是新发明）：

- **Kirzner**：创业者的功能是发现尚未被利用的失衡，推动市场趋向均衡。早期利润来自警觉，不是来自均衡状态下的「正常回报」。
- **Schumpeter**：长期利润来自新组合（新产品、新市场、新组织），会摧毁旧均衡。这更接近「结构化」之后的阶段。
- **Hayek**：有用的知识是分散的。价格、排队、抱怨、workaround、平台规则漏洞，都是知识的压缩形式。交易比调研更接近真实知识。
- **Byrne Hobart（The Diff, 2025）**：许多公司的超增长阶段看起来像套利；套利关闭后留下的是基础设施。「发现可利用的套利，本质上是经济体给第一个发现它的公司提供非稀释融资。」套利不能无限规模化，但套利者有时能把一笔交易做成一家公司。

因此：Kirzner 解释**起步**，Schumpeter 解释**留下**。把两者写成同一条直线，会误导搜索——你会去找「伟大公司的基因」，而不是找「此刻能成交的差」。

个人判断：互联网时代最常见、最被低估的失衡不是商品供需，而是**注意力/分发定价错误**。平台补贴、新算法、新社交表面、新搜索意图、线下无人认领的人流，都是「买流量的成本 < 成交后留下的价值」。这就是为什么 Distribution 必须进入模型，而且常常是起点，不是第 2 步。

## 3. 为什么成功公司早期几乎都有「借势 / 套利」阶段

不是因为创始人道德上投机，而是资源约束下的最优策略。

1. **均衡市场需要你还没有的东西。** 品牌、成本曲线、信任、密度、牌照，都是规模的结果。早期只能进入尚未被充分定价的角落。
2. **套利是最便宜的需求验证。** 问卷说「愿意」，交易说「付钱」。价差能覆盖获客和履约，说明至少有一边的真实约束被你碰到了。
3. **借势是穷公司的分发。** 你买不起品牌广告，就寄生在别人已经付钱堆起来的意图流上：Craigslist、Yahoo 目录、微信关系链、地推人海、SEO 残页、学术口碑、支付默认位。
4. **窗口本身在筛选。** 找得到廉价入口的人活下来；先做完美产品再找客户的人，多数死在「没人来」。
5. **资本有时会反转 UE 顺序。** 美团、Uber 类公司先放大再证明稳态 UE，那是因为当时资本把「市场份额」定价过高——这是另一层套利：便宜的钱 × 可规模化的局部垄断预期。这能解释例外，不能当默认打法。

反过来说：如果一个机会从第一天就要和成熟均衡市场正面撞（同等 CAC、同等成本、同等信任），它通常不是创业机会，是在给现有玩家打工。

## 4. 对线性模型的具体修正

### 4.1 起点不是固定的「先发现失衡」

至少三条同样有效的入口，最后都要完成「差 × 入口」匹配：

| 入口 | 问题 | 典型 |
|---|---|---|
| A. 失衡优先 | 哪里有人在超付、等待、workaround、规则空转？ | Airbnb 会议住房、Google 搜索质量 |
| B. 分发优先 | 我能廉价碰到谁？这条管子里能塞什么会立刻成交的东西？ | 拼多多 × 微信，腾讯 QQ 关系链后来分发一切 |
| C. 能力/成本差优先 | 我能把某件事做到别人 1/10 成本，或别人做不到的质量？ | Amazon 选品+周转，紫鸟来自卖家一线 know-how |

拼多多更接近 B→A：先有一条未被电商充分使用的社交分发管，再匹配下沉价格敏感需求。若坚持「先发现需求再找分发」，会漏掉这类机会。

### 4.2 分发不是营销附件，是机会函数的因子

机会不存在于「有需求」；存在于：

```
机会 = 失衡(Spread) × 分发入口(Access) × 可占有性(Appropriability) × 可交易性(Transactability)
```

任一项为 0，机会为 0。

- Spread：价差、信息差、地域差、时间差、规则差、质量差、信任差、产能闲置差、注意力差、成本结构差、资本成本差。
- Access：能以低于你所分得价差的成本，触达至少一侧会成交的人。
- Appropriability：平台、渠道、模仿者、监管不会在你完成学习之前把差抽走。
- Transactability：本周能发生一笔真金白银的交易，而不是「访谈验证」。

### 4.3 捕获阶梯是发现循环成功之后的事

```
最小交易 → 诚实 UE → 窗口内放大 → 结构化 → 用资产寻找下一层失衡
```

这是递归的。Amazon 用图书套利建物流和现金周期，再用物流去套利其他零售，再用内部闲置算力去套利企业 IT。腾讯用 IM 套利建关系链，再用关系链分发游戏、支付、内容。

原模型的「不断尝试 / 修正」应保留为外环，不要删掉。没有外环，内环只是一张漂亮的成功流程图。

### 4.4 「验证 UE 再放大」是默认，不是定律

默认应先证明：含 CAC、履约、退货、封禁/合规风险、自己的时间之后，贡献利润仍为正。

例外：当放大本身能改变 UE（双边市场密度、网络效应、学习曲线），且你能获得廉价资本时，可以先买密度。这是高风险路径。美团千团大战里大多数公司死在这条路上；活下来的是运营效率和后续高频品类接得住的那一个。

## 5. 案例：验证、部分反驳、以及各自真正结构化的是什么

案例用来检验模型的预测力，不用来证明「他们一开始就想到了终局」。长期愿景可以先于套利存在；但早期现金流和增长，仍然经常靠套利。Hobart 的判断在这里适用。

### 5.1 Airbnb — 强支持

- **失衡**：会议城市酒店供给刚性，住宅闲置；陌生人交易缺信任。
- **分发**：设计会议/DNC 的瞬时需求；后来把 Craigslist 上已有的住房意图流接到自己的交易闭环（未授权跨发，已被广泛记录）。
- **第一次套利**：气垫床 + 早餐，对酒店溢价的替代。
- **UE**：抽成；早期转化被烂照片拖死，专业摄影是在修转化而不是在「做品牌故事」。
- **结构化**：评价/保险/身份、供需密度、品牌、城市网络效应。Craigslist 入口关闭后，生意还在，因为交易和信任已经搬到自有系统。

预测：若只有会议套利、没有把交易搬进自有闭环，Airbnb 会停在活动黄牛层。

### 5.2 Amazon — 强支持，而且是多层叠加

- **失衡**：书的 SKU 长尾 vs 书店货架；邮购搜索成本高。
- **分发**：早期 Web / Yahoo 目录；1996 Associates 联盟——把别人的站点变成销售员。
- **第一次套利**：更全、更方便、经常更便宜；另有现金周期套利（客户先付款、供应商后结算）和早期跨州销售税空窗（Quill 案相关，属已记录的监管差）。
- **结构化**：飞轮（选品→流量→供应商→价格）、3P marketplace、物流、Prime、AWS。

Amazon 说明结构化不是一次完成，而是**用这一层套利留下的基础设施，去吃下一层差**。通俗展开见第 5.2 段落后的叠层说明：每一层赚到的现金和能力，变成下一层的成本优势，直到「卖书」不再是公司的定义。

叠层（个人判断，机制来自公开史实）：

1. 书店只能放约十万种书，世界上有几百万种 → 网上把长尾摆出来，这是选品差。
2. 客户刷卡马上付钱，出版社 30–90 天后才要钱 → 用客户的钱进货扩张，这是现金周期差。
3. 早期多州不收销售税 → 相对实体店的价格差。
4. Associates：别的网站已有流量，按成交抽成给他们 → 买分发，不买广告位。
5. 差开始变薄之后：让第三方入驻（3P），Amazon 抽成并让他们把货放进自己仓库（FBA）；Prime 让客户先付钱买「以后都从我这买」的权利；内部闲置服务器变成 AWS。每一层都是：旧套利关闭 → 留下的管子/仓库/习惯去吃新的差。

### 5.3 Google — 部分反驳线性顺序，支持「差 × 后来的分发锁」

反驳点：PageRank 不是先找到分发再套利。顺序更接近：信息检索质量差 → 产品本身即分发（更好的结果被口碑拉动）→ 两年后才用 AdWords 把「意图」卖给广告主。

支持点：

- 链接结构里藏着未被使用的排序信息，这是信息/质量差。
- AdWords 是注意力套利：广告主为「高意图点击」付的钱，远高于展示广告时代对同一次注意力的定价。
- 真正的终局结构是锁分发：默认搜索位、Chrome、Android、广告拍卖机制、数据反馈环。

对搜索框架的含义：技术/质量入口（路径 C）合法。不要因为「还不像套利」就丢掉；但商业化仍然是在给某个差定价。没有 AdWords，Google 可以是伟大产品，很难是伟大生意。

### 5.4 美团 — 强支持，并暴露「放大先于 UE」的死亡率

- **失衡**：本地非高峰产能闲置；美国 Groupon 模型已验证、中国供给和地推组织方式不同。
- **分发**：校园和地面部队；后来腾讯流量；再后来超级 App 自有分发。
- **第一次套利**：用折扣把消费者批量卖给商家当获客。
- **UE**：行业级早期很差。千团大战是资本套利叠加商业套利；多数模仿者在价差（含资本）关闭时死亡。
- **结构化**：高频外卖、骑手网络、到店密度、商家工具。团购价差关闭后，留下的是本地生活基础设施。

预测：只会团购、不会迁到高频履约网络的玩家，应在 2013 前后失去超额利润。这与行业事实一致。

### 5.5 拼多多 — 强支持「分发可以是第一因子」

- **失衡**：淘宝/天猫上移后，下沉价格敏感需求与白牌/农产品供给匹配不足。
- **分发**：微信关系链、拼团、砍价、小程序。获客成本相对阿里付费流量是数量级差。黄峥侧的公开表述是「货找人」——先聚合需求，再反推供给。
- **第一次套利**：社交裂变 CAC vs 电商广告 CAC；产地/工厂价 vs 品牌零售价。
- **结构化**：独立 App、C2M、农产品供应链、广告变现、Temu 把同一套「极致价格 × 新分发表面」再套一遍。

关键教训：微信裂变会被平台限制（诱导分享多次被打击，属公开报道）。拼多多活下来是因为把用户和交易迁到自有 App，并往供应链做结构。只会砍一刀、没有自有资产的社交电商，窗口一关就结束。

### 5.6 腾讯 — 强支持「产品即分发，再把分发变成税」

- **失衡**：ICQ 已验证即时通讯，中国本地化和网络条件未满足。
- **第一次套利**：产品复制（OICQ/QQ）；广告市场不成熟时，用虚拟物品给注意力定价（QQ 秀等），这是变现套利。
- **分发**：通讯工具天然病毒；后来 ISP/预装；再后来整个社交图成为中国最大分发资产。
- **结构化**：关系链上叠游戏、支付、公众号、小程序。公司的终局不是「更好的聊天」，是「别人获客必须经过的管」。

腾讯证明：最强的结构化，是把曾经的套利入口变成**别人做套利时必须向你交税的基础设施**。

### 5.7 紫鸟浏览器 — 支持，且是「卖铲人」嵌套结构；结构化尚未完成

公开事实（招股书及相关报道，2025–2026，可能随上市进程更新）：

- 紫讯技术将产品定义为跨境电商店铺营运基础设施；行业俗称指纹/防关联浏览器。
- 创始人杨金河有跨境卖家经历，产品来自一线被关联封店的痛点（路径 C：能力/know-how 优先）。
- 模式：预付费订阅，按设备月费；高毛利、应收账款接近零、合约负债高——负营运资金。
- 收入高度集中在浏览器；正在推 LinkFox 等第二曲线。风险包括平台政策、客户 ARPU/留存压力。

模型解读（个人判断，不是招股书口径）：

- **失衡**：平台「一店一主体」规则 vs 卖家规模化需要多店铺；西方同类工具贵、对中文卖家支持差；卖家用虚拟机/多设备的成本高。
- **分发**：跨境卖家社群、教程、SEO「指纹浏览器」、代理渠道——都是高意图、低品牌广告依赖的入口。
- **第一次套利**：向正在做平台规则差的人卖镐和铲。这是嵌套套利：客户套利平台，紫鸟套利「客户对封号的恐惧 + 多开成本」。
- **UE**：预付费 SaaS 几乎是教科书级好 UE；这只说明套利层成立。
- **结构化关键测试**：若平台执法收紧或卖家转向品牌化少账号，防关联刚需会收缩。长期资产必须变成「店铺操作系统」（权限、协作、插件、采集、AI 运营），让续费理由从「防封」变成「离开的切换成本」。若做不到，这是一门可以很暴利、但均值回归风险极高的套利生意，不是终局公司。

紫鸟特别适合当搜索框架的试金石：好 UE ≠ 已结构化。不要把「很赚钱」误读成「已经是长期资产」。

## 6. 用于寻找机会的通用框架（向前搜，不是向后解释）

### 6.1 先画差，再问入口，不要先写愿景

每天只收集能回答下面一句的观察：

> 谁在用笨办法补一个洞，补洞的成本明显高于洞本身的价值，而我能碰到这些人？

笨办法 = workaround。排队、Excel、黄牛、多开账号、地推、群发、假资质、人肉比价、开两套系统，都是失衡的可见形式。

### 6.2 差的检索表

按表扫描，比「找痛点」具体。每条都要写：差的两边各是什么、为什么还没闭合、闭合力量是谁。

| 类型 | 你在找什么 | 早期形态 | 结构方向 |
|---|---|---|---|
| 价格 | 同一物不同价 | 倒货、白牌 | 自有品牌、供应链 |
| 信息 | 你知道对方不知道的 | 咨询、选品、数据 | 独家数据/流程 |
| 地理 | 同物不同地 | 跨境、海淘、区域代理 | 本地履约/品牌 |
| 时间 | 现在 vs 以后 | 囤货、预售、闲置时段 | 预测与库存系统 |
| 注意力 | CAC < 成交价值 | SEO、社群、补贴、线下 | 自有渠道/品牌 |
| 规则 | 条文与现实已错位 | 擦边、牌照空窗、平台漏洞 | 牌照、合规本身变壁垒 |
| 质量/技术 | 同样价格好一个数量级，或同样功能便宜一个数量级 | 更好的搜索、更便宜的火箭 | IP、成本曲线 |
| 信任 | 陌生人无法成交 | 担保、评价、托管 | 声誉系统 |
| 产能闲置 | 固定成本已沉没 | 团购、云、顺风车 | 市场密度 |
| 劳动/成本 | 工资或效率差 | 外包、C2M | 工艺与品牌 |
| 资本 | 钱比项目便宜 | 烧钱换密度 | 活下来后的垄断租金 |
| 工具层 | 别人在套利，缺镐 | 紫鸟、支付、物流、广告工具 | 工作流入口、切换成本 |

### 6.3 三条入口如何汇合

任选一条开始，但**没有匹配前不要融资式放大**：

- 只有差、没有入口：日记，不是生意。
- 只有入口、没有差：流量生意，很快变成买量亏钱。
- 只有能力、没有人和差：作品，不是公司。

匹配成功的最小证据：一笔真实交易，且你能说出对方是从哪条具体入口来的。

### 6.4 七问（按顺序，通不过就停）

1. **差是什么，为什么还没闭合？** 写不清「为什么没闭合」，多半是你看不见的成本（信任、履约、封禁、售后、法律）。
2. **我是否有一条入口，使触达一个成交用户的成本 < 我能分到的价差？**
3. **本周能否完成一笔真实交易？** 不能，就还在幻想层。
4. **诚实 UE 是否为正？** 计入获客、履约、退款、风险（封号、罚款、平台抽成上调）、创始人时间。
5. **若下月有 100 人复制，还剩下什么？** 剩下的才可能是结构的种子。
6. **每一笔交易沉淀了什么，使下一笔更便宜或价差更宽？** 数据、评价、内容、关系、库存、工艺、品牌、成本下降。若每笔交易都是独立的，你在做工，不是在做公司。
7. **若原始价差归零，是否还有生意？** 没有 → 收割，不要按公司来融资扩张。有 → 才配「放大 + 结构化」。

决策规则：

- 1–4 过、5–7 弱：可以做现金生意，按套利管理（控制库存、不建大团队、随时准备退出）。
- 1–4 过、6–7 强：按公司做，核心工作从「多赚几笔」换成「每笔都在砌资产」。
- 1–3 过、4 不过：不是没需求，是分发太贵或履约太重。先换入口或削履约，不要先加功能。

### 6.5 结构化的可检验定义

「品牌、网络效应、数据」太容易事后贴标签。向前看，只认四类可观察变化：

1. **你的 CAC 相对竞争对手在下降**（自有分发、口碑、默认位、地推 densify）。
2. **客户离开你的成本在上升**（工作流嵌入、双边密度、财务/数据迁移）。
3. **同样一单的可变成本在下降**（工艺、规模采购、自动化、密度）。
4. **价差的解释变量从「市场没发现」变成「你改变了生产函数」**（你不再是在两个价格之间搬东西，而是在把输入变成别人短期复制不了的输出）。

满足 0 条：套利。满足 1 条：开始像生意。满足 2 条以上：开始像资产。

### 6.6 均值回归：决定你该「放大」还是「收割」

估计窗口，不要假装没有窗口：

| 闭合力量 | 快 | 慢 |
|---|---|---|
| 复制 | 手法公开、资本密集 | 需要组织资本、本地 densify、牌照 |
| 平台 | 规则一改、算法一调 | 你已迁到自有关系 |
| 监管 | 一纸禁令 | 你变成被监管的持牌方 |
| 需求 | 节日/疫情/补贴 | 结构性习惯改变 |

窗口短于你建资产所需时间 → 放大是自杀，应收割。  
窗口长、且每笔交易在砌上述四类变化 → 放大是正确的。

## 7. 这个框架会故意漏掉什么

- **长周期深科技**：早期可能没有可卖的套利，只有里程碑。仍可用路径 C 看「成本曲线何时翻过现有方案」。不要硬套「本周第一笔交易」。
- **已在均衡里卷的存量市场**：框架会给出「不要进」，这是功能，不是缺陷。
- **愿景驱动但拒绝交易验证的项目**：框架会判为未完成发现循环。个人判断：多数该判。

## 8. 和旧模型的关系（避免静默覆盖）

| | 旧模型 | 本模型 |
|---|---|---|
| 保留 | 尝试、局部失衡、低成本交易、信号、加码、修正 | 作为发现循环外环 |
| 新增 | — | 分发作为因子；可占有性；UE；均值回归；结构化检验 |
| 2026-08-13 | — | 第三层：分发入口 ≠ 分发权；创造剩余 / 接触剩余 / 占有剩余 |
| 修正 | 隐含「先有需求」 | 分发优先、能力优先同样合法 |
| 修正 | 「加码」无条件 | 加码必须过 UE 或明确的密度赌注，且窗口未关 |

旧模型没有错，它是搜索算法的一半。缺的是：匹配函数、占有条件、以及何时停止把套利当公司来做。

## 9. 事实 / 判断 / 待验证

**已验证（公开史实与理论）：** Airbnb 会议住房与 Craigslist 分发；Amazon 图书长尾、联盟、现金周期；Google 搜索质量先于广告变现；美团团购到本地生活；拼多多微信社交分发与下沉供给；腾讯 IM 到关系链平台；紫鸟预付费浏览器 SaaS 及平台政策风险（以招股披露为准，可能过时）。Kirzner / Schumpeter / Hobart「套利提供非稀释融资、留下基础设施」。

**个人判断：** 互联网创业里，分发差的权重大于商品供需差；「最终成功」的充分条件是结构化，不是套利本身；紫鸟目前更接近「套利层 UE 极好、结构层未完成」。

**假设，待用真实机会回测：**

1. 用七问筛一批自己能碰到的机会，看事后 6–12 个月是「收割正确 / 做成公司 / 假信号」哪一类更多。
2. 分发优先的机会，结构化失败率是否高于失衡优先（因为管道不归你）。
3. 卖铲生意（工具层）是否系统性地比直接套利更容易做 UE、更难做终局资产。

## 10. 术语与人物（防混淆）

- **UE / Unit Economics**：以「一个客户 / 一笔订单 / 一台订阅设备」为单元算账。收入是否盖过获客、履约、退款、风险。好 UE = 每多做一个单元，现金和利润通常是正的，而且这个正数在规模变大时不会立刻翻负。
- **分发入口 vs 分发权**：入口是你能碰到人；权是你能决定别人碰到谁。创业早期要的是前者，终局争的是后者。
- **Byrne Hobart**：Newsletter *The Diff* 作者，兼写 *Capital Gains*。背景跨广告/SEO（含 Yahoo）、对冲基金研究（SAC/Point72）、数据公司。不是一线操盘的明星创始人，是把公司和金融市场当成同一套「价差如何闭合」来写的分析者。原句对照见 `thinking/business/potential-energy-and-gaps/hobart-arbitrage-infrastructure.md`。核心篇：2025 *Arbs Close, Infrastructure Remains*。「带基础设施的套利」是本库转述，不是他的原标题。
