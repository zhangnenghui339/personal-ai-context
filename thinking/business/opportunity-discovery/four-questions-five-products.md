# 读创业史的四个问题（五案）

- Date: 2026-08-14
- Status: working method
- 替代读法：「它做对了什么产品？」
- 四问：借了谁的势 → 第一批客户从哪来 → 当时没被抹平的 Gap → 借来的 Distribution/Gap 转化成什么自有资产
- 判断：第二问最常被省略。只复制产品，复制的是结果，不是让结果成立的势。

## 方法

四问对应本库三层：势和第一批客户是接触剩余；Gap 是创造/发现剩余的切口；自有资产是占有剩余。第二问不是营销花絮，是机会函数里的 Access。没有它，Gap 只是观察。

读史时禁止用后来的产品定义倒推起源。先写清第一批人是怎么碰到的，再写产品。

## 五案

### 1. QQ

| 问 | 答 |
|---|---|
| 借谁的势 | ICQ 已验证的 IM 形态；深圳电信的带宽和服务器；网吧作为共享电脑；后来中国移动梦网的计费管道。 |
| 第一批客户从哪来 | 同城聊天室截流（碧海银沙一类）；电脑杂志/报纸的下载说明；网吧桌面预装，老板手把手教「网络寻呼机」；电信信息港比华南竞品更稳带来的口碑转向。不是应用商店，也不是广告。 |
| 当时的 Gap | 要私聊、跨城、留联系，公共聊天室做不到；PC 贵、上网贵，人在网吧；有用户不会收费，广告商还没把互联网当正经媒体。 |
| 转化成什么 | 关系链。短信分成和 ISP 管道会关（清网）；留下的是 QQ 号、好友列表，再叠虚拟物品、游戏、支付、微信。产品可抄，1999 年的网吧桌面和 2001 年的梦网计费抄不到。 |

只抄一个 IM，得到的是 2000 年前后那上百家做寻呼软件的公司。

### 2. Airbnb

| 问 | 答 |
|---|---|
| 借谁的势 | 设计大会/民主党大会造成的酒店刚性短缺；Craigslist 上已经在找非酒店住宿的意图流。 |
| 第一批客户从哪来 | 起源：气垫床交易。放量：两条寄生 Craigslist 的路，官方故事常只讲一条。向外：把 Airbnb 房源发到 Craigslist，截需求。向内（外面少说）：把已经在 Craigslist 上挂房的人当成高意图供给名单，用其联系方式邀请到 Airbnb。第一批可规模化的房东，很大程度是对手已经标好的「我有空房、我要成交」。 |
| 当时的 Gap | 会议酒店刚性；Craigslist 有意图和联系方式，没有信任、支付、摄影和成交闭环。对手把高意图身份公开或半公开地摊在分类广告上，等于免费 CRM。 |
| 转化成什么 | 评价、身份、保险、摄影、密度、品牌。联系方式管道一关（屏蔽、诉讼、邮箱失效），交易必须已经搬进自有账号。 |

省略「向内」这一问，Airbnb 会变成分享经济寓言。加上它，第二问才完整：第一批供给不是从零教育出来的，是从对手的身份图里搬过来的。今日再抄短租网站，抄不到的是当年那份还可触达的名单，不是页面。

详见 `thinking/business/opportunity-discovery/airbnb-competitor-identity.md`。

### 3. 拼多多

| 问 | 答 |
|---|---|
| 借谁的势 | 微信关系链和小程序；腾讯资本与支付；淘宝上移后空出的下沉价格带；工厂/农产品找不到品牌溢价出口。 |
| 第一批客户从哪来 | 微信里的拼团、砍价、分享。人不是搜「拼多多」来的，是被熟人拉进来的。小程序是第一现场，App 是后来迁走的。这一问被省略后，故事变成「社交电商模式创新」——模式抄得了，2015–2017 年微信还允许的裂变强度抄不了。 |
| 当时的 Gap | 下沉用户会买、不会用搜索电商表达需求；工厂有货、没有便宜获客；微信流量相对阿里付费流量是数量级差。 |
| 转化成什么 | 自有 App、C2M/农产品供应链、广告变现、Temu 把同一套再套一遍。砍一刀会被平台限制；留下的是用户和供给。只抄拼团按钮、没有微信那几年的势，就是下一场社交电商烈士。 |

### 4. 美团

| 问 | 答 |
|---|---|
| 借谁的势 | 美国 Groupon 已验证的团购模型；2010 年千团大战的资本和媒体注意力；校园和地面部队能碰到的本地商家与学生；后来腾讯流量。 |
| 第一批客户从哪来 | 地推。学生、商户，一张张谈、一单一单核。不是 App 商店自然量。团购网站外观家家能抄；能把第一批核销做出来的，是人海和城市密度，不是页面。 |
| 当时的 Gap | 本地非高峰产能闲置；商家要客、不会自己做互联网获客；消费者要折、不信任单独一家店的营销。行业级 UE 很差——Gap 存在不代表能留下。 |
| 转化成什么 | 高频外卖、骑手网、到店密度、商家工具。团购价差和补贴关闭后，留下履约和本地生活超级 App。抄 Groupon 页面的公司，多数死在第一批客户的获客成本和核销上，不是死在「产品不像」。 |

### 5. 紫鸟浏览器

| 问 | 答 |
|---|---|
| 借谁的势 | 跨境平台把「一店一主体」写成规则，从而制造多开需求；西方指纹浏览器贵、对中文卖家支持差；跨境卖家社群和教程已经是高意图现场；创始人自己当过卖家。 |
| 第一批客户从哪来 | 卖家圈子，不是「SaaS 内容营销打品牌」。痛点从自己被关联封店来，第一批人是同类卖家。渠道是社群、教程、SEO「指纹浏览器」。省略第二问，会以为这是通用浏览器创新；其实第一批人已经在做平台规则差，工具是卖铲。 |
| 当时的 Gap | 平台执法不完全 vs 卖家要规模化多店铺；虚拟机/多设备成本高；中文世界缺好用、预付、可团队权限的隔离环境。 |
| 转化成什么 | 预付费订阅、店铺权限/协作、插件入口；正在推的运营/AI 第二曲线是结构测试。防关联刚需随平台政策均值回归。好 UE ≠ 已把 Gap 变成离开也付费的操作系统。抄一个指纹浏览器，没有跨境社群的第一批卖家，获客会变成对称广告战。 |

## 对照：为什么第二问决定抄不抄得走

| 产品 | 故事里常写的 | 真正第一批客户 | 今天抄产品会丢掉的势 |
|---|---|---|---|
| QQ | 做好用的 IM | 聊天室、网吧桌面、电信 | 共享电脑 + 梦网计费 |
| Airbnb | 分享经济 | 大会住房，再接 Craigslist | 会议尖峰 + 未授权意图流 |
| 拼多多 | 社交电商 | 微信拉人 | 那几年的裂变余量 |
| 美团 | 本地生活超级 App | 地推核销 | 千团资本 + 地面组织 |
| 紫鸟 | 店铺基础设施 | 卖家社群里的同类人 | 跨境圈高意图 + 创始人身份 |

第二问答不出「具体从哪扇门进来的第一千个人」，这个案例就还不能用来指导行动。能答出，才知道：此刻同一扇门还在不在、过路费涨了没有、第一碰还在不在你手里。

## 和本库模型

四问是读史协议，不是另一套机会方程。机会仍是 Gap × 入口 × 可占有 × 可交易。读史时把「入口」写成「第一批客户从哪来」，是为了防止用后来的品牌故事把 Access 洗掉。
