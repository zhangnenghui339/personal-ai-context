# cases/candidates/ —— 待分析 / 待比较的候选案例

- Status: 暂存区，非结论

## 用途

放**还没形成结论**的案例和方向：

- 后面可能要深入分析的原始案例 / 素材
- 先保存、后面要横向比较的一批方向

与 `cases/` 根目录的区别：根目录放**已完成的结论型案例**（历史复盘、完整周期、可复用案例库）；本文件夹放**过程中的、待定的**。

## 约定

- 一个候选一个文件；`Status:` 标 `candidate / 待分析` 或 `待比较`。
- 分析出结论、或确认要长期留用后，再移到 `cases/` 根目录或相应的库文件，并更新 `thinking/business/README.md`。
- 放弃的直接删，不必留痕。
