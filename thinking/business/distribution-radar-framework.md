# 分发雷达（Distribution Radar）：探测量化未被定价的流量与意图流动

- Date: 2026-08-22
- Status: working model / operational SOP
- Scope: 完善商业闭环第一步「借分发」的探测机制，构建系统化扫描「高流量平台新增阵地、介质跃迁、宿主生态开放、突发事件与高价值意图流动」的分发雷达体系。

---

## 一、 为什么必须建立「分发雷达」？

**分发不是碰运气，而是一套对「未被竞价定价的人流、注意力与高价值意图」的早期预警系统。**

如果等到某个渠道已经被行业广泛报道、培训班到处开课时才进场（如今天的亚马逊美国站普通 PPC、成熟期 Facebook 投流、国内天猫直通车），**该渠道的广告税（CAC）已经被充分竞价打平，套利空间归零**。

「分发雷达」的核心使命：**在水库刚蓄水、堤坝刚开闸、或者用户注意力刚搬家的前 3~6 个月，先于大厂和正规军识别出「低成本/无竞价/高意图」的流量真空。**

---

## 二、 分发雷达的四大扫描波段（4-Band Radar）

```
                     【分发雷达四大扫描波段】
                                │
     ┌──────────────────────────┼──────────────────────────┐
     │                          │                          │
【波段 1: 巨头拓荒与新阵地】 【波段 2: 介质跃迁与AEO搜索】 【波段 3: 宿主生态与插件】
 (Platform Expansions)     (Medium & GEO Shift)       (Host & App Ecosystems)
                                │
                   【波段 4: 规则断裂与新词真空】
                     (Regulatory & Trend Vacuum)
```

---

### 波段 1：巨头战略拓荒与新进军阵地（Platform Expansions / Subsidized Reach）

* **触发机制**：万亿级巨头为了向资本市场证明增长，强行开辟新国家、新业务线或新功能模块。**此时平台处于“免疫系统最弱、甚至自掏腰包补贴流量”的红利期**。
* **雷达监测点**：
  1. **巨头跨国拓荒**：TikTok Shop 刚进驻的欧洲/拉美新国家、Temu 刚开放半托管的新站点、亚马逊新开的中东/拉美站点；
  2. **平台内部新推一级入口**：微信新推的视频号带货组件、小红书新开放的买手分销系统、Instagram/YouTube 新推的某种互动格式；
* **特征信号**：**平台主动给自然流量扶持、广告系统尚未完善（无须竞价）、对搬运/新卖家审核宽松**。

---

### 波段 2：介质跃迁与下一代搜索入口（Medium Shift & AEO/GEO）

* **触发机制**：人类寻找信息、解决问题和消费决策的**「第一入口」发生代际大搬家**。
* **雷达监测点**：
  1. **生成式 AI 搜索与引用（AEO / GEO）**：ChatGPT Search、Perplexity、Claude Artifacts、Google AI Overviews。用户不再点传统 10 个蓝链，而是看 AI 总结；
  2. **年轻一代的搜索介质迁移**：Z 世代把 TikTok / 小红书 / Reddit 当作第一搜索引擎（搜旅游攻略、好物评测、踩坑指南，放弃 Google/百度）；
  3. **社区高权重借壳（Parasite SEO）**：Google 算法偏袒 Reddit、Quora、GitHub、Medium，导致社区帖子霸占搜索首页。
* **特征信号**：**传统 SEO 玩家尚未反应过来、大模型引用抓取规则存在结构化 Schema 漏洞、社区帖子里聚集着极度明确的购买咨询**。

---

### 波段 3：宿主开放生态与轻应用卡位（Host Ecosystems & In-App Marketplaces）

* **触发机制**：某个巨型 App 开放了应用内插件、小程序或 API 市场，允许第三方开发者直接在它庞大的用户池内构建应用。
* **雷达监测点**：
  1. **超级通讯软件生态**：Telegram Mini Apps（TON 生态，背靠 9 亿不需下载 App 的即时用户）、Discord Bot / App Directory；
  2. **生产力与商业工具插件市场**：Shopify App Store 新 API、Chrome Web Store 新规范、Figma / Canva 插件生态、WordPress 官方市场；
  3. **AI 时代的智能体协议与工具市场**：OpenAI GPTs Store、各大模型厂商的 MCP (Model Context Protocol) 插件生态。
* **特征信号**：**直接接入已有认证和绑卡支付的成熟用户池、无需跨端跳出、应用商店内搜索关键词处于零竞争状态**。

---

### 波段 4：规则断裂、政策新规与突发新词真空（Regulatory Lag & Trend Hijacking）

* **触发机制**：外界突发黑天鹅事件、地缘法律变动、或底层颠覆性技术发布，**瞬间在全网引爆千万级搜索，但全网供给页面为零**。
* **雷达监测点**：
  1. **技术断裂新词**：某个新开源大模型架构（如 DeepSeek/Llama 新版本）、新开发框架、新硬件协议；
  2. **政策与签证突发**：某国新出台免签政策、欧盟新颁布数据/合规法案（如 AI Act）、美国新关税法案；
  3. **行业灾难与替代品搜索**：某大厂突然倒闭/停服、某核心工具突然涨价 10 倍，用户全网寻找“{倒闭工具} 替代品”。
* **特征信号**：**Google Trends 曲线呈 90 度垂直上升、Google 前两页全是不相关的推特动态或新闻残页、零专业工具页面**。

## 三、 分发雷达的「三级过滤漏斗」（如何判断是不是好洼地？）

扫描到流量线索后，通过以下三步漏斗快速过滤，防止被“虚假垃圾流量”浪费时间：

```
[Filter 1: 意图质量 (Commercial Intent)] 
  ↳ 问：这个流量是“纯看热闹的娱乐粉”，还是“带着明确任务/钱包/痛点的购买意图”？
  ↳ 规则：优先捕获【搜索词带动作（How to / Best tool for / Buy / vs）】的高意图流。

[Filter 2: 竞价与广告负载 (Ad Load & Competition)] 
  ↳ 问：在这个渠道里，大厂是否已经开始砸重金竞价？前三名是不是已经被天价广告占满？
  ↳ 规则：选择【自然流量占比 > 70%、广告位未满、大厂正规军未入场】的渠道。

[Filter 3: 提取与转正难度 (Extraction Friction)] 
  ↳ 问：平台允许把人导到自己的独立网页/Email，还是完全封闭在平台内？
  ↳ 规则：选择【允许挂外链/个人简介、或能通过免费工具/资源包无摩擦索取邮箱】的渠道。
```

## 四、 操盘手的日常雷达监控武器库（Tooling & Feeds）

| 监测目标 | 核心监控工具与信号源 | 日常关注指标 |
|---|---|---|
| **全球搜索与长尾词** | Ahrefs / SEMrush / Google Trends / Exploding Topics | 突发搜索词增长率（> 300%）、Keyword Difficulty (KD < 10) |
| **社区高热意图与吐槽** | Reddit (GummySearch / F5Bot) / Quora / X Pro (TweetDeck) | “Is there a tool for...”、“Why is {Software} so expensive” |
| **开源与开发者技术代差** | GitHub Trending / Hacker News / Product Hunt | 连续 3 天 Star 暴涨的新协议/新工具形态 |
| **应用市场与插件生态** | Chrome Web Store 增长榜 / Shopify App Store 新上榜 / Telegram App Center | 新分类上线、评分低但安装量暴涨的粗糙工具（供给真空） |
| **大模型抓取与引用** | Perplexity 引用来源追踪 / ChatGPT Search 知识库抓取日志 | 哪些特定结构的表格与对比文章被 AI 优先抓取为答案第一信源 |
