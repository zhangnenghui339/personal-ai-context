# 项目角色

先读 `projects/<name>/status.md`。`status.md` 代表当前状态。

## 怎么做

- 再按需：`overview.md`、`decisions.md`、`todo.md`。
- 同一主题冲突时，采用日期更新且有证据的记录。
- 未在本轮重新核验的旧事实，标「可能过时」。
- `projects/archive/` 不参与默认检索。
- 新项目从 `projects/_template/` 复制四个基础文件，不要另起一套结构。

## OpenClaw 雷达

入口是 `projects/openclaw-radars/status.md`，再读 `overview.md`。方法论在 `thinking/business/distribution-radar/`，需要时再开商业角色。GitHub 只记结构与状态；密钥与收件配置不进仓库、不从旧 README 反推 live cron。
